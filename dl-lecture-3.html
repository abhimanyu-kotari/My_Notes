Module 03 Optimization Masterclass

Neural Network Optimizers: From Gradient Descent to Adam

A textbook-grade treatise on first-order optimization algorithms in deep learning: resource bottlenecks of Batch GD, stochastic noise mechanics of SGD, tensor vectorization of Mini-Batch SGD, physical momentum via exponentially weighted moving averages (EWMA), coordinate-wise adaptive scaling in AdaGrad, dying learning rate mitigation in RMSprop, and unified moment estimation with analytical bias correction in Adam.

1. The Optimization Paradigm in Supervised Deep Learning

In deep neural architectures, Optimization constitutes the operational engine of learning. Once a model maps input activations forward to predict targets $\hat{\mathbf{y}} = f(\mathbf{x}; \boldsymbol{\theta})$ and evaluates empirical loss $\mathcal{L}(\mathbf{y}, \hat{\mathbf{y}})$, the optimizer executes the mathematical procedure to iteratively calibrate parameters $\boldsymbol{\theta} = \{\mathbf{W}, \mathbf{b}\}$ toward the global infimum of the objective surface.

Formally, optimization seeks the parameter configuration $\boldsymbol{\theta}^*$ that minimizes the Empirical Risk across a dataset of $N$ training samples:

$$\boldsymbol{\theta}^* = \arg\min_{\boldsymbol{\theta}} J(\boldsymbol{\theta}) = \arg\min_{\boldsymbol{\theta}} \frac{1}{N} \sum_{i=1}^{N} \mathcal{L}\left( y^{(i)}, f\left(\mathbf{x}^{(i)}; \boldsymbol{\theta}\right) \right)$$
💡
The Core First-Order Update Law: All modern gradient-based optimizers stem from Cauchy’s classical method of steepest descent. At step $t$, parameter vector $\mathbf{w}$ is adjusted along the negative gradient direction scaled by learning rate $\eta > 0$: $$\mathbf{w}_{t} = \mathbf{w}_{t-1} - \eta \nabla_{\mathbf{w}} J(\mathbf{w}_{t-1})$$ The fundamental differences among optimizers revolve around two questions: How many samples are evaluated to compute $\nabla J$? and How is the scalar step size $\eta$ adapted across directions and time?

2. Dissecting Training Terminology: Batch, Epoch & Iteration

To systematically reason about optimization algorithms, one must formally differentiate three foundational operational concepts:

Parameter Partition

Batch Size ($B$)

The exact number of training instances propagated through the network in a single forward pass before gradients are aggregated and weights are updated.

Complete Cycle

Epoch

One complete traversal wherein the learning algorithm has evaluated and updated upon every individual record in the entire training dataset of $N$ instances.

Discrete Step

Iteration ($I$)

A single parameter update step. The total number of iterations required to execute one full epoch is precisely $I = \lceil N / B \rceil$.

$$\text{Total Iterations per Epoch } (I) = \left\lceil \frac{N}{B} \right\rceil, \quad \text{Total Optimizer Steps Across Training} = I \times \text{Epochs}$$

For example, training on an enterprise dataset of $N = 1,000,000$ records across $100$ epochs yields:

  • Batch GD ($B = 1,000,000$): $1$ iteration per epoch $\implies 100$ total weight updates.
  • Mini-Batch SGD ($B = 1,000$): $1,000$ iterations per epoch $\implies 100,000$ total weight updates.
  • Stochastic GD ($B = 1$): $1,000,000$ iterations per epoch $\implies 100,000,000$ total weight updates.

3. Batch Gradient Descent (BGD): Determinism & Computational Bottlenecks

Batch Gradient Descent (BGD) computes the exact mathematical gradient of the empirical cost function across the entire corpus of $N$ samples simultaneously:

$$\mathbf{w}_{t} = \mathbf{w}_{t-1} - \eta \cdot \frac{1}{N} \sum_{i=1}^{N} \nabla_{\mathbf{w}} \mathcal{L}\left( y^{(i)}, f\left(\mathbf{x}^{(i)}; \mathbf{w}_{t-1}\right) \right)$$

3.1 Mathematical Strengths

  • Deterministic Convergence: Because the gradient is evaluated over all $N$ samples, gradient variance is mathematically zero ($\sigma^2 = 0$). The loss monotonically decreases on convex functions with a sufficiently small learning rate.
  • Theoretical Predictability: Asymptotically converges to the true local or global minimum without trajectory jitter.

3.2 Architectural Bottlenecks & Hardware Limits

⚠️
The Out-of-Memory (OOM) Catastrophe: During backpropagation, every intermediate hidden layer activation $\mathbf{Z}^{(l)}, \mathbf{A}^{(l)}$ must be cached in RAM/VRAM to evaluate partial derivatives via the chain rule. Storing activation tensors for $N = 1,000,000$ high-dimensional inputs exceeds the physical VRAM capacity of state-of-the-art accelerators (e.g., NVIDIA H100 80GB), triggering catastrophic memory paging or program crashes.

Furthermore, on non-convex deep learning loss landscapes filled with saddle points and local minima, BGD’s zero-stochasticity nature causes it to stagnate permanently on zero-gradient plateaus ($\nabla J \approx \mathbf{0}$).

4. Stochastic Gradient Descent (SGD): High-Variance Trajectories

To eradicate the $O(N)$ memory bottleneck, Stochastic Gradient Descent (SGD) sets the batch size to $B = 1$. It evaluates the loss and updates model parameters immediately upon processing each individual training instance $(\mathbf{x}^{(i)}, y^{(i)})$:

$$\mathbf{w}_{t} = \mathbf{w}_{t-1} - \eta \cdot \nabla_{\mathbf{w}} \mathcal{L}\left( y^{(i)}, f\left(\mathbf{x}^{(i)}; \mathbf{w}_{t-1}\right) \right)$$

4.1 The Expectation Proof & Gradient Variance

Statistically, the single-sample gradient $\mathbf{g}_t^{(i)}$ is an unbiased estimator of the true population gradient $\nabla J(\mathbf{w})$:

$$\mathbb{E}_{i \sim \mathcal{U}(1, N)}\left[ \nabla_{\mathbf{w}} \mathcal{L}\left(y^{(i)}, f(\mathbf{x}^{(i)}; \mathbf{w})\right) \right] = \frac{1}{N} \sum_{i=1}^{N} \nabla_{\mathbf{w}} \mathcal{L}\left(y^{(i)}, f(\mathbf{x}^{(i)}; \mathbf{w})\right) = \nabla J(\mathbf{w})$$

However, because individual sample losses differ drastically across the dataset, the variance of this single-sample estimator is exceptionally large:

$$\operatorname{Var}\left(\mathbf{g}_t^{(i)}\right) = \mathbb{E}\left[ \|\mathbf{g}_t^{(i)} - \nabla J(\mathbf{w})\|^2 \right] = \sigma^2 \gg 0$$

4.2 The "Zig-Zag" Oscillation Pathology

This massive variance manifests geometrically as violent zig-zag fluctuations (noise). While this noise provides the beneficial property of allowing the optimizer to bounce out of shallow sub-optimal local minima, it severely impedes convergence near the true minimum, causing the weights to oscillate perpetually around the optimal point without settling down.

5. Mini-Batch SGD & Vectorized Hardware Acceleration

Mini-Batch Gradient Descent represents the universally adopted industry standard compromise between Batch GD and pure SGD. It partitions the training corpus into uniform mini-batches of size $B$ (typically $B \in \{32, 64, 128, 256, 512, 1024\}$):

$$\mathbf{w}_{t} = \mathbf{w}_{t-1} - \eta \cdot \frac{1}{B} \sum_{i=1}^{B} \nabla_{\mathbf{w}} \mathcal{L}\left( y^{(i)}, f\left(\mathbf{x}^{(i)}; \mathbf{w}_{t-1}\right) \right)$$

5.1 Variance Reduction Mechanics

By the Central Limit Theorem, aggregating gradients over $B$ independent and identically distributed samples scales down the estimator variance by exactly a factor of $B$:

$$\operatorname{Var}\left( \frac{1}{B} \sum_{i=1}^{B} \mathbf{g}_t^{(i)} \right) = \frac{\sigma^2}{B}$$

Setting $B = 100$ reduces gradient variance by $99\%$ compared to pure SGD, dramatically attenuating noisy oscillations while fitting comfortably inside GPU tensor memory.

5.2 The Ravine Bottleneck

Despite variance reduction, Mini-Batch SGD struggles acutely in Ravines—loss surface contours where surface curvature is substantially steeper in one dimension than in another (an ill-conditioned Hessian matrix with high condition number $\kappa = \lambda_{\max} / \lambda_{\min} \gg 1$).

Along the steep ravine walls, gradient components are massive, causing violent transverse oscillations. Along the gently sloping floor toward the minimum, gradients are tiny, resulting in agonizingly slow forward progress.

6. Exponentially Weighted Moving Average (EWMA) & Mathematical Smoothening

To eradicate high-frequency transverse oscillations, deep learning borrows a fundamental filtering technique from time series calculus: the Exponentially Weighted Moving Average (EWMA).

6.1 Recursive Formulation

Let $\theta_1, \theta_2, \dots, \theta_t$ denote a discrete sequence of noisy observations across successive optimization steps. The exponentially smoothed state $v_t$ is computed via the first-order recursive filter:

$$v_t = \beta \cdot v_{t-1} + (1 - \beta) \cdot \theta_t, \quad v_0 = 0$$

where $\beta \in [0, 1)$ is the smoothing coefficient (decay factor).

6.2 Series Expansion & Exponential Memory

Unrolling the recursion backwards reveals that $v_t$ is a weighted linear combination of all historical observations weighted by exponentially decaying powers of $\beta$:

$$\begin{aligned} v_t &= (1 - \beta)\theta_t + \beta \left( (1 - \beta)\theta_{t-1} + \beta v_{t-2} \right) \\ &= (1 - \beta)\theta_t + \beta(1 - \beta)\theta_{t-1} + \beta^2(1 - \beta)\theta_{t-2} + \dots + \beta^{t-1}(1 - \beta)\theta_1 \\ &= (1 - \beta) \sum_{i=0}^{t-1} \beta^i \cdot \theta_{t-i} \end{aligned}$$

6.3 Derivation of the Effective Lookback Window

At what time lag does the historical weight decay to approximately $1/e \approx 36.8\%$ of its initial value?

$$\beta^{\tau} = \frac{1}{e} \implies \tau \ln(\beta) = -1 \implies \tau = \frac{-1}{\ln(\beta)}$$

Using the first-order Taylor expansion $\ln(\beta) = \ln(1 - (1 - \beta)) \approx -(1 - \beta)$ for $\beta \approx 1$:

$$\tau \approx \frac{-1}{-(1 - \beta)} = \frac{1}{1 - \beta}$$
  • For $\beta = 0.9$: Lookback window $\approx \frac{1}{1 - 0.9} = 10$ historical steps.
  • For $\beta = 0.95$: Lookback window $\approx \frac{1}{1 - 0.95} = 20$ historical steps.
  • For $\beta = 0.99$: Lookback window $\approx \frac{1}{1 - 0.99} = 100$ historical steps.

7. SGD with Momentum: The Heavy Ball Physical Paradigm

Proposed by Boris Polyak (1964), SGD with Momentum applies EWMA directly to the gradient vector. It models optimization as a heavy particle rolling down a potential energy surface with physical friction.

7.1 Mathematical Formulation

Let $\mathbf{g}_t = \nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}_{t-1})$ denote the stochastic gradient evaluated on the current mini-batch. The velocity vector $\mathbf{v}_t$ and parameter update rule are defined as:

$$\mathbf{v}_t = \beta \mathbf{v}_{t-1} + (1 - \beta) \mathbf{g}_t$$
$$\mathbf{w}_t = \mathbf{w}_{t-1} - \eta \mathbf{v}_t$$

(Note: An equivalent common formulation absorbs $(1 - \beta)$ into $\eta$, defining $\mathbf{v}_t = \beta \mathbf{v}_{t-1} + \eta \mathbf{g}_t$ and $\mathbf{w}_t = \mathbf{w}_{t-1} - \mathbf{v}_t$).

7.2 Why Momentum Neutralizes Ravine Oscillations

⚡
Vector Cancellation Geometry: Across an anisotropic ravine, the transverse gradients point in opposing directions at successive steps ($+g_y$ then $-g_y$). Taking their running weighted average causes them to cancel out toward zero ($\sum g_y \approx 0$). In contrast, the longitudinal gradients along the valley floor point consistently forward ($+g_x$ and $+g_x$). The velocity accelerates along this consistent direction, propelling the optimizer rapidly toward the global minimum while dampening oscillations.

8. AdaGrad: Coordinate-Wise Adaptation & The Dying LR Pathology

While momentum smoothens directional trajectory, all parameters $\mathbf{w}_j$ still share the identical global scalar learning rate $\eta$. In 2011, Duchi, Hazan, and Singer introduced AdaGrad (Adaptive Gradient Algorithm) to dynamically customize the learning rate per parameter.

8.1 Mathematical Formulation

AdaGrad maintains a running sum of squared past gradients $\mathbf{G}_t$ for every individual coordinate:

$$\mathbf{G}_t = \mathbf{G}_{t-1} + \mathbf{g}_t \odot \mathbf{g}_t = \sum_{\tau=1}^{t} \mathbf{g}_\tau^2$$
$$\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{\sqrt{\mathbf{G}_t + \epsilon}} \odot \mathbf{g}_t$$

where $\odot$ denotes element-wise Hadamard multiplication, and $\epsilon \approx 10^{-8}$ is a smoothing term that prevents numerical division-by-zero.

8.2 Adaptive Scaling Dynamics

  • Frequent / High-Gradient Parameters: Parameters associated with large gradient updates accumulate massive $\mathbf{G}_t$ values. The effective learning rate $\eta / \sqrt{\mathbf{G}_t + \epsilon}$ shrinks drastically, preventing overshoot.
  • Infrequent / Sparse Feature Parameters: Infrequently updated parameters maintain small $\mathbf{G}_t$ values. Their effective learning rate remains high, allowing the model to learn rapidly from rare features (critical for NLP and embeddings).

8.3 The Fatal Flaw: The Monotonic Freezing Pathology

🛑
Mathematical Proof of AdaGrad's Dying Learning Rate: Because every term added to $\mathbf{G}_t$ is non-negative ($\mathbf{g}_t^2 \ge 0$), $\mathbf{G}_t$ is a monotonically non-decreasing sequence: $$\mathbf{G}_t \ge \mathbf{G}_{t-1} \ge \dots \ge \mathbf{G}_0 \implies \lim_{t \to \infty} \mathbf{G}_t = +\infty$$ Consequently, the effective learning rate monotonically converges to zero: $$\lim_{t \to \infty} \frac{\eta}{\sqrt{\mathbf{G}_t + \epsilon}} = 0$$ In deep neural networks requiring tens of thousands of iterations, the learning rate drops to near zero early in training, completely freezing the weights and halting learning long before arriving at the minimum.

9. RMSprop & AdaDelta: Overcoming the Dying Learning Rate

In Lecture 6 of his 2012 Coursera course, Geoffrey Hinton proposed RMSprop (Root Mean Squared Propagation)—an unpublished yet revolutionary algorithm designed specifically to resolve AdaGrad’s dying learning rate flaw.

9.1 The RMSprop Moving Window Solution

Instead of monotonically summing squared gradients over all eternity, RMSprop replaces the sum with an exponentially decaying average of squared gradients:

$$\mathbf{s}_t = \beta \mathbf{s}_{t-1} + (1 - \beta) \mathbf{g}_t^2$$
$$\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{\sqrt{\mathbf{s}_t + \epsilon}} \odot \mathbf{g}_t$$

Typical hyperparameters: Decay factor $\beta = 0.9$ (or $0.99$), initial learning rate $\eta = 0.001$, stabilizer $\epsilon = 10^{-8}$.

9.2 Why RMSprop Rescues Deep Training

Because $\mathbf{s}_t$ uses an EWMA with decay $\beta$, historical gradients older than $\frac{1}{1 - \beta}$ steps are exponentially forgotten. If gradients suddenly become small, $\mathbf{s}_t$ decreases, causing the effective step size to dynamically expand again! The learning rate never permanently freezes.

9.3 AdaDelta (Zeiler, 2012)

A concurrent extension, AdaDelta, takes RMSprop one step further by eliminating the explicit learning rate hyperparameter $\eta$ entirely. By matching physical parameter update units, AdaDelta replaces $\eta$ with the root mean square of past parameter displacements $\operatorname{RMS}[\Delta \mathbf{w}]_{t-1}$.

10. The Adam Optimizer: Adaptive Moment Estimation

Published by Diederik Kingma and Jimmy Ba in 2014, Adam (Adaptive Moment Estimation) represents the undisputed apex of first-order optimization in contemporary deep learning. Adam unifies the two greatest algorithmic innovations:

  1. Momentum (First Moment): Directional smoothing via exponentially decaying running average of past gradients.
  2. RMSprop (Second Moment): Adaptive coordinate scaling via exponentially decaying running average of past squared gradients.

10.1 First and Second Uncentered Moment Vectors

At step $t$, with stochastic mini-batch gradient $\mathbf{g}_t$:

$$\mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1) \mathbf{g}_t \quad \text{(First Moment: Mean)}$$
$$\mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2) \mathbf{g}_t^2 \quad \text{(Second Moment: Uncentered Variance)}$$

Standard default coefficients: $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-8}$.

10.2 Mathematical Derivation of Bias Correction

Because $\mathbf{m}_0 = \mathbf{0}$ and $\mathbf{v}_0 = \mathbf{0}$ at step $t=0$, initial moment estimates are severely biased toward zero, particularly when $\beta_1$ and $\beta_2$ are close to $1$.

Let us formally derive the bias correction for $\mathbf{m}_t$. Unrolling the recursion:

$$\mathbf{m}_t = (1 - \beta_1) \sum_{i=1}^{t} \beta_1^{t-i} \mathbf{g}_i$$

Taking expectations of both sides, assuming the true gradient expectation $\mathbb{E}[\mathbf{g}_i] = \nabla J$ remains stationary over the local window:

$$\begin{aligned} \mathbb{E}[\mathbf{m}_t] &= \mathbb{E}\left[ (1 - \beta_1) \sum_{i=1}^{t} \beta_1^{t-i} \mathbf{g}_i \right] \\ &= \mathbb{E}[\mathbf{g}_t] \cdot (1 - \beta_1) \sum_{i=1}^{t} \beta_1^{t-i} \\ &= \mathbb{E}[\mathbf{g}_t] \cdot (1 - \beta_1) \frac{1 - \beta_1^t}{1 - \beta_1} \\ &= \mathbb{E}[\mathbf{g}_t] \left( 1 - \beta_1^t \right) \end{aligned}$$

Notice the residual scaling term $(1 - \beta_1^t)$! At $t=1$ with $\beta_1 = 0.9$, $(1 - 0.9^1) = 0.1$, meaning the raw moment $\mathbf{m}_1$ is only $10\%$ of its true magnitude! Dividing by $(1 - \beta_1^t)$ completely cancels this bias:

$$\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t}$$

10.3 The Master Adam Parameter Update Equation

$$\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \odot \hat{\mathbf{m}}_t$$
$$\mathbf{b}_t = \mathbf{b}_{t-1} - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t^{(b)}} + \epsilon} \odot \hat{\mathbf{m}}_t^{(b)}$$

Practice Task 1: Vectorized Mini-Batch Data Generator & Iteration Tracker

Problem Statement: Write a modular Python function in pure NumPy that partitions a dataset of $N$ instances into shuffled mini-batches of size $B$, ensuring that any remaining samples in an incomplete final batch are accurately retained. Compute total epochs, batch size, iterations per epoch, and verify array batch shapes.

python 
import numpy as np

def get_mini_batches(X, y, batch_size=32, shuffle=True):
    """
    Generates balanced mini-batches from feature matrix X and target vector y.
    """
    n_samples = X.shape[0]
    indices = np.arange(n_samples)
    
    if shuffle:
        np.random.shuffle(indices)
        
    batches = []
    num_complete_batches = n_samples // batch_size
    
    for k in range(num_complete_batches):
        batch_idx = indices[k * batch_size : (k + 1) * batch_size]
        batches.append((X[batch_idx], y[batch_idx]))
        
    # Handling remaining uneven instances
    if n_samples % batch_size != 0:
        remainder_idx = indices[num_complete_batches * batch_size :]
        batches.append((X[remainder_idx], y[remainder_idx]))
        
    return batches

Practice Task 2: Momentum vs. Vanilla Gradient Descent on an Anisotropic Ravine

Problem Statement: Implement a simulation optimizing the ill-conditioned quadratic function $f(x, y) = 0.1 x^2 + 2.0 y^2$ starting at $(x_0, y_0) = (10.0, 10.0)$. Compare standard Gradient Descent ($\beta = 0$) against SGD with Momentum ($\beta = 0.9$) across $50$ steps.

python 
import numpy as np

def cost_func(x, y):
    return 0.1 * (x ** 2) + 2.0 * (y ** 2)

def gradients(x, y):
    return 0.2 * x, 4.0 * y

def run_optimizer(use_momentum=False, lr=0.15, beta=0.9, steps=50):
    x, y = 10.0, 10.0
    vx, vy = 0.0, 0.0
    
    for t in range(steps):
        gx, gy = gradients(x, y)
        
        if use_momentum:
            vx = beta * vx + (1.0 - beta) * gx
            vy = beta * vy + (1.0 - beta) * gy
            x -= lr * vx
            y -= lr * vy
        else:
            x -= lr * gx
            y -= lr * gy
            
    return x, y, cost_func(x, y)

# Benchmark
x_gd, y_gd, loss_gd = run_optimizer(use_momentum=False)
x_mom, y_mom, loss_mom = run_optimizer(use_momentum=True)

print(f"Standard GD Loss after 50 steps : {loss_gd:.6f} | Coords: ({x_gd:.3f}, {y_gd:.3f})")
print(f"Momentum GD Loss after 50 steps : {loss_mom:.6f} | Coords: ({x_mom:.3f}, {y_mom:.3f})")

Practice Task 3: AdaGrad Dying Learning Rate vs. RMSprop Recovery

Problem Statement: Write a Python script implementing the updates of AdaGrad and RMSprop on a linear parameter receiving persistent unit gradients ($g_t = 1.0$) across $500$ steps. Record and display the effective learning rate at steps $1, 10, 100,$ and $500$ to demonstrate AdaGrad's premature decay vs. RMSprop's equilibrium.

python 
import numpy as np

def simulate_lr_decay(initial_lr=0.1, steps=500, beta=0.9, eps=1e-8):
    adagrad_G = 0.0
    rmsprop_S = 0.0
    
    adagrad_eff_lrs = []
    rmsprop_eff_lrs = []
    
    for t in range(1, steps + 1):
        g_t = 1.0  # Persistent unit gradient
        
        # AdaGrad Sum
        adagrad_G += g_t ** 2
        adagrad_lr = initial_lr / (np.sqrt(adagrad_G) + eps)
        
        # RMSprop Moving Average
        rmsprop_S = beta * rmsprop_S + (1.0 - beta) * (g_t ** 2)
        rmsprop_lr = initial_lr / (np.sqrt(rmsprop_S) + eps)
        
        if t in [1, 10, 100, 500]:
            adagrad_eff_lrs.append((t, adagrad_lr))
            rmsprop_eff_lrs.append((t, rmsprop_lr))
            
    return adagrad_eff_lrs, rmsprop_eff_lrs

ada_res, rms_res = simulate_lr_decay()

print("Step | AdaGrad Effective LR | RMSprop Effective LR")
print("--------------------------------------------------")
for (t, a_lr), (_, r_lr) in zip(ada_res, rms_res):
    print(f"{t:4d} | {a_lr:20.6f} | {r_lr:20.6f}")

Practice Task 4: Complete Production-Grade Adam Optimizer Class in Pure NumPy

Problem Statement: Write a modular, production-grade object-oriented implementation of the complete Adam optimizer supporting multi-dimensional tensors, first and second moment decay, and analytical bias corrections. Test the class on a 2-parameter optimization problem and output convergence trajectory metrics.

python 
import numpy as np

class AdamOptimizer:
    def __init__(self, params_shape, lr=0.01, beta1=0.9, beta2=0.999, eps=1e-8):
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.t = 0  # Step counter
        
        # First and second moment buffers
        self.m = np.zeros(params_shape, dtype=np.float64)
        self.v = np.zeros(params_shape, dtype=np.float64)
        
    def step(self, params, grads):
        self.t += 1
        
        # 1. Update biased 1st moment estimate (Momentum)
        self.m = self.beta1 * self.m + (1.0 - self.beta1) * grads
        
        # 2. Update biased 2nd raw moment estimate (RMSprop)
        self.v = self.beta2 * self.v + (1.0 - self.beta2) * (grads ** 2)
        
        # 3. Compute bias-corrected estimates
        m_hat = self.m / (1.0 - self.beta1 ** self.t)
        v_hat = self.v / (1.0 - self.beta2 ** self.t)
        
        # 4. Compute updated parameters
        params_updated = params - (self.lr / (np.sqrt(v_hat) + self.eps)) * m_hat
        return params_updated

# Verification on Non-Convex Objective f(x, y) = x^2 + 10y^2
if __name__ == '__main__':
    theta = np.array([5.0, -5.0], dtype=np.float64)
    optimizer = AdamOptimizer(params_shape=theta.shape, lr=0.1)

    for epoch in range(1, 101):
        # Gradient of f(x, y) = [2x, 20y]
        grad = np.array([2.0 * theta[0], 20.0 * theta[1]])

13. Summary & Master Optimizer Comparison Matrix

A consolidated reference guide comparing the mathematical formulation, memory footprint, strengths, and failure modes across the complete spectrum of deep learning optimizers:

Optimizer Primary Equation Memory Overhead Standard Hyperparameters Key Advantages Vulnerabilities & Pitfalls
Batch GD $\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{N}\sum \mathbf{g}^{(i)}$ $O(N)$ high RAM $\eta = 0.01$ Exact, deterministic gradient; zero noise. OOM on large datasets; trapped on saddle points.
SGD $\mathbf{w}_t = \mathbf{w}_{t-1} - \eta \mathbf{g}^{(i)}$ $O(1)$ minimal $\eta = 0.01$ Instant updates; escapes shallow local minima. High variance; severe zig-zagging; slow convergence.
Mini-Batch SGD $\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{B}\sum_{i=1}^B \mathbf{g}^{(i)}$ $O(B)$ GPU-tuned $\eta = 0.01, B = 32\text{--}256$ Exploits GPU tensor cores; reduced variance. Oscillates in ravines; uniform step size across dims.
Momentum $\mathbf{v}_t = \beta \mathbf{v}_{t-1} + (1-\beta)\mathbf{g}_t$ $O(K)$ extra velocity $\eta = 0.01, \beta = 0.9$ Dampens ravine oscillations; accelerates in valleys. Can overshoot minima if momentum is tuned too high.
AdaGrad $\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{\sqrt{\mathbf{G}_t + \epsilon}} \odot \mathbf{g}_t$ $O(K)$ squared sum $\eta = 0.01, \epsilon = 10^{-8}$ Per-coordinate adaptive step sizes; great for sparse data. Monotonically shrinking learning rate halts training.
RMSprop $\mathbf{s}_t = \beta \mathbf{s}_{t-1} + (1-\beta)\mathbf{g}_t^2$ $O(K)$ running variance $\eta = 0.001, \beta = 0.9, \epsilon = 10^{-8}$ Rescues AdaGrad via EWMA; prevents learning rate death. Lacks directional momentum smoothing on numerator.
Adam $\mathbf{w}_t = \mathbf{w}_{t-1} - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \odot \hat{\mathbf{m}}_t$ $2 \times O(K)$ ($\mathbf{m}, \mathbf{v}$) $\eta = 0.001, \beta_1 = 0.9, \beta_2 = 0.999, \epsilon = 10^{-8}$ Combines Momentum + RMSprop + Bias Correction. Best overall. May occasionally fail to converge on specialized non-convex bounds.

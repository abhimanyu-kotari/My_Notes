Lists & Tuples

What is this topic? Lists and Tuples are collections that allow you to group multiple values together in a single variable. Lists are flexible and can be modified anytime (like adding or removing items), while Tuples are locked and cannot be changed once created.
Why do we use it? Instead of creating 50 separate variables for 50 student marks, you store them in one clean list. We use lists for dynamic data like shopping cart items or playlists, and tuples for permanent data that should never be altered, like GPS coordinates or color codes.

01. What is a List & Creation Syntax

1. The Architectural Need for Sequential Collections

In previous lectures, variables stored individual primitive scalar values—a single number, a boolean flag, or a textual string. Consider a software scenario where a teacher needs to track the test scores of a cohort of students.

With primitive scalar variables, managing multiple entries rapidly becomes unwieldy and non-scalable:

python 
# Anti-Pattern: Declaring independent variables for a sequence of related values
marks1 = 94.4
marks2 = 87.0
marks3 = 95.2
marks4 = 66.4
marks5 = 45.1
# What happens when a cohort has 50, 100, or 10,000 students?
# Managing thousands of variable names is unmaintainable and computationally infeasible.

2. Formal Definition of a Python List

A list is a built-in, ordered, and mutable sequential data structure in Python that holds a collection of values under a single identifier. In Python's internal type system, it belongs to the class list.

Lists in Python serve as the high-level equivalent of arrays found in languages like C, C++, or Java, but with two monumental advantages:

  1. Dynamic Sizing: You do not need to pre-allocate memory or declare a fixed size up-front; lists expand or shrink dynamically as elements are added or removed.
  2. Heterogeneous Typing: Unlike static arrays in C/Java which restrict all elements to a single data type, Python lists can store values of different data types simultaneously.
Syntax & Structure of a List

Lists are declared using square brackets [ ], with elements separated by commas:

marks = [94.4, 87.0, 95.2, 66.4, 45.1]
python 
# Creating and inspecting a numeric list
marks = [94.4, 87.0, 95.2, 66.4, 45.1]

print("List contents:", marks)
print("Type of marks:", type(marks))
print("Length of list:", len(marks))
Terminal Output:
List contents: [94.4, 87.0, 95.2, 66.4, 45.1]
Type of marks: <class 'list'>
Length of list: 5

3. Heterogeneous Elements in a Single List

A single Python list can seamlessly store strings, integers, floats, and booleans together. This makes lists ideal for representing composite real-world entities (such as a student profile) without creating custom classes for simple groupings:

python 
# Heterogeneous record containing string, float, integer, and boolean types
student = ["Karan", 85.5, 19, "Delhi", True]

print("Student Profile:", student)
print("Number of fields:", len(student))
Terminal Output:
Student Profile: ['Karan', 85.5, 19, 'Delhi', True]
Number of fields: 5

02. List Indexing & List Mutability

1. Zero-Based Positional Indexing

Just like strings, lists in Python are sequentially ordered. Each element in the list is bound to a numerical coordinate called an index.

  • The first element resides at index 0.
  • The second element resides at index 1.
  • The final element resides at index len(list) - 1.
Memory Layout of List Indexing

Given the list marks = [94.4, 87.0, 95.2, 66.4, 45.1]:

Element Value 94.4 87.0 95.2 66.4 45.1
Positive Index 0 1 2 3 4
Negative Index -5 -4 -3 -2 -1
⚠️
The IndexError Boundary Trap

Attempting to access an index that does not exist (e.g. marks[5] when the list has only 5 items from index 0 to 4) immediately halts execution with an IndexError: list index out of range.

2. Mutability vs. Immutability: The Core Distinction

The most critical architectural distinction between Python strings and Python lists is mutability:

  • Immutable (Cannot be changed): In strings, individual characters cannot be reassigned in place. Attempting text[0] = 'a' causes a TypeError: 'str' object does not support item assignment.
  • Mutable (Can be changed in place): In lists, elements at any valid index can be directly modified, overwritten, or updated without creating a brand-new list object in memory.
python 
# 1. Strings are Immutable (Read-Only Items)
text = "hello"
# text[0] = "y"  --> Raises TypeError: 'str' object does not support item assignment

# 2. Lists are Mutable (In-Place Modifications Allowed)
student = ["Karan", 85.5, 19, "Delhi"]
print("Original student name:", student[0])

# Reassign index 0 in place
student[0] = "Arjun"
student[1] = 92.0

print("Updated student list:", student)
Terminal Output:
Original student name: Karan
Updated student list: ['Arjun', 92.0, 19, 'Delhi']

03. List Slicing & Sublists

1. Sublist Extraction Mechanics

Just as slicing a string produces a substring, slicing a list produces a sublist (a shallow copy of a continuous subsection of the original list).

Formal Syntax: list_name[starting_index : ending_index]

Boundary Rules for List Slicing
  • starting_index is INCLUSIVE (the element at this index is included).
  • ending_index is EXCLUSIVE (the slice stops at ending_index - 1; the element at ending_index is omitted).
  • Sublist Length Formula: len(sublist) = ending_index - starting_index.
python 
marks = [85, 94, 76, 63, 48]
# Indices: 0   1   2   3   4

# Slice from index 1 to index 4 (exclusive of 4: indices 1, 2, 3)
sublist = marks[1:4]
print("marks[1:4]:", sublist)  # [94, 76, 63]

# Slice from index 0 to index 3 (exclusive of 3: indices 0, 1, 2)
print("marks[0:3]:", marks[0:3])  # [85, 94, 76]
Terminal Output:
marks[1:4]: [94, 76, 63]
marks[0:3]: [85, 94, 76]

2. Omitted Indices & Negative Slicing

Python allows omitting slice boundaries, substituting default values:

  • list[:end] → Defaults to index 0 (starts at the beginning of the list).
  • list[start:] → Defaults to len(list) (slices through the final element).
  • list[:] → Slices the entire list from index 0 to the end, returning a fresh shallow copy.
  • Negative Slicing: Uses negative indices counting from the right end (e.g. marks[-3:-1] slices from index -3 up to -2).
python 
marks = [85, 94, 76, 63, 48]

# 1. Omitted starting index (defaults to 0)
print("marks[:3]  =", marks[:3])   # [85, 94, 76]

# 2. Omitted ending index (defaults to len)
print("marks[2:]  =", marks[2:])   # [76, 63, 48]

# 3. Negative Index Slicing (-3 is 76, -1 is 48 exclusive)
print("marks[-3:-1] =", marks[-3:-1]) # [76, 63]

# 4. Extract last 3 elements
print("marks[-3:] =", marks[-3:])   # [76, 63, 48]
Terminal Output:
marks[:3] = [85, 94, 76]
marks[2:] = [76, 63, 48]
marks[-3:-1] = [76, 63]
marks[-3:] = [76, 63, 48]

04. Built-in List Methods

1. The In-Place Mutation Behavior of List Methods

Before examining list methods, master this foundational Python design principle:

⚠️
Critical Concept: In-Place Modification vs. Return Value

In strings (which are immutable), methods like str.capitalize() cannot touch the original string; they construct and return a new string.

In lists (which are mutable), mutating methods such as list.append(), list.sort(), and list.reverse() modify the existing list directly in memory and return None.

Therefore, writing result = list.sort() assigns None to result! Never try to assign the return value of an in-place list method.

2. Deep Dive into the 6 Core List Methods

Method Arguments Operation & Behavior Return Value
list.append(element) element Adds a single element to the very end of the list. Mutates list in place. None
list.sort() reverse=False (opt) Sorts list elements in ascending order in place. Pass reverse=True for descending. None
list.reverse() None Inverts the order of elements in the list completely in place. None
list.insert(idx, el) idx, element Inserts element at specific index idx, shifting subsequent elements right. None
list.remove(element) element Removes the first occurrence of element from the list. None
list.pop(idx) idx (default: -1) Deletes and removes element at specified index. If omitted, removes last element. Removed element
python 
# Comprehensive demonstration of all core list methods
nums = [2, 1, 3]
print("Initial list:", nums)

# 1. list.append(el): Adds element to the end
nums.append(4)
print("After append(4):", nums)  # [2, 1, 3, 4]

# 2. list.sort(): Sorts in ascending order in place
nums.sort()
print("After sort():", nums)      # [1, 2, 3, 4]

# 2b. list.sort(reverse=True): Sorts in descending order
nums.sort(reverse=True)
print("After sort(reverse=True):", nums)  # [4, 3, 2, 1]

# 3. list.reverse(): Inverts the list elements
nums.reverse()
print("After reverse():", nums)   # [1, 2, 3, 4]

# 4. list.insert(idx, el): Inserts value 5 at index 1
nums.insert(1, 5)
print("After insert(1, 5):", nums) # [1, 5, 2, 3, 4]

# 5. list.remove(el): Removes the first occurrence of value 5
nums.remove(5)
print("After remove(5):", nums)   # [1, 2, 3, 4]

# 6. list.pop(idx): Deletes and returns element at index 2 (value 3)
popped_val = nums.pop(2)
print("Popped element:", popped_val)  # 3
print("After pop(2):", nums)      # [1, 2, 4]
Terminal Output:
Initial list: [2, 1, 3]
After append(4): [2, 1, 3, 4]
After sort(): [1, 2, 3, 4]
After sort(reverse=True): [4, 3, 2, 1]
After reverse(): [1, 2, 3, 4]
After insert(1, 5): [1, 5, 2, 3, 4]
After remove(5): [1, 2, 3, 4]
Popped element: 3
After pop(2): [1, 2, 4]

3. Sorting Strings and Characters Lexicographically

The .sort() method applies equally to text strings and alphabetical characters. Python sorts string items in lexicographical order (alphabetical order based on ASCII/Unicode numeric values):

python 
# Sorting string items alphabetically
fruits = ["banana", "litchi", "apple", "mango"]
fruits.sort()
print("Ascending fruits:", fruits)  # ['apple', 'banana', 'litchi', 'mango']

fruits.sort(reverse=True)
print("Descending fruits:", fruits) # ['mango', 'litchi', 'banana', 'apple']
Terminal Output:
Ascending fruits: ['apple', 'banana', 'litchi', 'mango']
Descending fruits: ['mango', 'litchi', 'banana', 'apple']

05. Introduction to Tuples

1. What is a Tuple?

A tuple is a built-in Python data type that lets developers create an immutable ordered sequence of values.

Conceptually, a tuple can be thought of as the immutable sibling of a list:

  • Like lists, tuples preserve sequence order, support 0-based indexing, allow negative indexing, and support slicing.
  • Unlike lists, tuples cannot be modified, resized, or mutated once initialized in memory. You cannot add new elements, delete existing elements, or change items at any index.
Syntax: Parentheses Delimiters

While lists use square brackets [ ], tuples are defined using standard parentheses ( ):

tup = (87, 64, 33, 95, 76)
python 
# Declaring and inspecting a tuple
tup = (87, 64, 33, 95, 76)

print("Tuple contents:", tup)
print("Data type:", type(tup))     # <class 'tuple'>
print("Length:", len(tup))           # 5
print("Element at index 0:", tup[0]) # 87
Terminal Output:
Tuple contents: (87, 64, 33, 95, 76)
Data type: <class 'tuple'>
Length: 5
Element at index 0: 87

2. The Immutability Enforced by Python

Just like strings, attempting item reassignment on a tuple triggers an immediate runtime exception:

python 
tup = (10, 20, 30)

# Reading an element is legal:
print(tup[0])  # 10

# Attempting to assign or mutate an item raises an exception:
# tup[0] = 50
# TypeError: 'tuple' object does not support item assignment
💡
Why Do Tuples Exist if Lists Already Store Sequences?

1. Data Integrity & Write-Protection: Tuples provide a guarantee that data cannot be altered accidentally by downstream functions.
2. Memory & Performance Efficiency: Because tuples have a fixed size, Python allocates a compact, contiguous memory block without the over-allocation overhead required by dynamic lists.
3. Dictionary Keys & Set Members: Because tuples are immutable, they possess fixed hash values (they are hashable) and can be used as keys in dictionaries, whereas lists cannot.

06. Tuple Syntax & The Single-Element Trap

1. Declaring Empty Tuples

An empty tuple containing zero elements is created using empty parentheses ():

python 
empty_tup = ()
print(empty_tup)        # ()
print(type(empty_tup))  # <class 'tuple'>

2. The Infamous Single-Element Tuple Trap

One of the most notorious syntactic traps for beginner Python developers occurs when attempting to create a tuple containing exactly one element.

⚠️
The Parentheses Ambiguity Trap

In mathematics and Python syntax, parentheses ( ) are used for operator precedence grouping (e.g. (5 + 2) * 3).

Therefore, when Python encounters tup = (1), it interprets the parentheses as mathematical grouping around the integer 1. The variable is inferred as type int, NOT a tuple!

Similarly, tup = ("hello") is evaluated as type str.

The Solution: The Mandatory Trailing Comma Rule

To instruct the Python parser that parentheses denote a single-element tuple rather than an arithmetic grouping expression, you must append a trailing comma immediately after the value:

single_tup = (1,) # Correct! Evaluates to <class 'tuple'>
str_tup = ("hello",) # Correct! Evaluates to <class 'tuple'>
python 
# INCORRECT: Omission of comma creates a scalar integer
fake_tup = (1)
print(fake_tup, "is type:", type(fake_tup))      # 1 is type: <class 'int'>

# CORRECT: Trailing comma identifies the literal as a tuple
real_tup = (1,)
print(real_tup, "is type:", type(real_tup))      # (1,) is type: <class 'tuple'>

# Single string element with trailing comma
word_tup = ("hello",)
print(word_tup, "is type:", type(word_tup))      # ('hello',) is type: <class 'tuple'>
Terminal Output:
1 is type: <class 'int'>
(1,) is type: <class 'tuple'>
('hello',) is type: <class 'tuple'>

3. Multiple Elements & Optional Trailing Comma

When declaring tuples with two or more elements (e.g. (1, 2, 3)), the internal comma delimiters already disambiguate the syntax from mathematical grouping. Thus, a final trailing comma (e.g. (1, 2, 3,)) is completely optional.

07. Tuple Indexing & Slicing

1. Positional Indexing in Tuples

Tuples support the exact same 0-based positive indexing and negative backwards indexing as strings and lists:

python 
grades = ("A", "B", "C", "D")

print("First element (index 0):", grades[0])   # 'A'
print("Second element (index 1):", grades[1])  # 'B'
print("Final element (index -1):", grades[-1])  # 'D'
Terminal Output:
First element (index 0): A
Second element (index 1): B
Final element (index -1): D

2. Tuple Slicing

Slicing a tuple produces a new tuple containing the specified sub-sequence. The same rule applies: the starting index is inclusive, and the ending index is exclusive.

python 
tup = (1, 2, 3, 4, 5)

# Slicing from index 1 to 3 (exclusive of 3 -> elements at index 1 and 2)
slice_res = tup[1:3]
print("tup[1:3] =", slice_res)        # (2, 3)

# Omitted start index
print("tup[:2]  =", tup[:2])         # (1, 2)

# Slicing to the end
print("tup[3:]  =", tup[3:])         # (4, 5)

# Negative index slicing
print("tup[-3:] =", tup[-3:])        # (3, 4, 5)
Terminal Output:
tup[1:3] = (2, 3)
tup[:2] = (1, 2)
tup[3:] = (4, 5)
tup[-3:] = (3, 4, 5)

08. Built-in Tuple Methods

1. Why Tuples Have Far Fewer Methods Than Lists

Because tuples are strictly immutable, all modifying methods that mutate sequences—such as .append(), .insert(), .remove(), .pop(), .sort(), and .reverse()—do not exist on tuples.

Tuples provide two essential read-only search and inquiry methods:

Method Arguments Operation Return Value
tup.index(element) element Searches for element and returns the 0-based index of its first occurrence. int (raises ValueError if absent)
tup.count(element) element Counts and returns the total frequency of occurrences of element in the tuple. int (returns 0 if absent)
python 
# Demonstrating tup.index() and tup.count()
nums = (1, 2, 3, 2, 4, 2, 5)

# 1. tup.index(value): Locate index of first occurrence of value 2
first_idx = nums.index(2)
print("First occurrence of value 2 is at index:", first_idx)  # Index 1

# 2. tup.count(value): Count frequency of value 2
total_twos = nums.count(2)
print("Frequency of value 2 in tuple:", total_twos)            # 3 times

# Count an element that does not exist
print("Frequency of value 99 in tuple:", nums.count(99))      # 0
Terminal Output:
First occurrence of value 2 is at index: 1
Frequency of value 2 in tuple: 3
Frequency of value 99 in tuple: 0

Task 02 Algorithmic Logic Palindrome list.copy()
Write a Python program to check whether a list contains a palindrome of elements.
Mathematical Concept & Strategy:

A palindrome is any sequence that reads identically forward and backward (e.g. strings like "racecar" or lists like [1, 2, 3, 2, 1] and ['m', 'a', 'a', 'm']).

  1. Create a separate duplicate of the original list using list.copy() (this avoids mutating the original list in place).
  2. Reverse the copied list using copy_list.reverse().
  3. Compare the original list with the reversed copy using ==.
  4. If copy_list == original_list, the elements form a palindrome; otherwise, they do not.
View Python Solution & Explanation
python 
# Task 2: Palindrome List Checker
list1 = [1, 2, 3, 2, 1]

# Step 1: Create a distinct shallow copy of list1
copy_list1 = list1.copy()

# Step 2: Reverse the copy in place
copy_list1.reverse()

# Step 3: Compare original with reversed copy
if copy_list1 == list1:
    print("Result: The list is a PALINDROME")
else:
    print("Result: The list is NOT a palindrome")

# Testing with a non-palindrome list:
list2 = [1, 2, 3]
copy_list2 = list2.copy()
copy_list2.reverse()

if copy_list2 == list2:
    print("Result: list2 is a PALINDROME")
else:
    print("Result: list2 is NOT a palindrome")
Terminal Output:
Result: The list is a PALINDROME
Result: list2 is NOT a palindrome

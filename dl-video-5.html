The Perceptron Trick: How to Train a Perceptron from Scratch

In this 51-minute deep-dive, Professor Nitish Singh unveils the training algorithm of the perceptron. Before touching formal loss functions and derivatives, he teaches the intuitive geometric heuristic known as the "Perceptron Trick"—showing how a misclassified point physically pulls or pushes the decision line. He derives the unified Rosenblatt learning rule and codes a complete Perceptron classifier in pure NumPy.

Watch Official Lecture on YouTube ↗

01. The Learning Problem: Starting from Random Weights

In Video 04, we saw that once we have weights $w_1, w_2$ and bias $b$, making a prediction is trivial: compute $z = w_1 x_1 + w_2 x_2 + b$ and apply the step function.

But where do the weights come from?

When you initialize a neural network, you don't know the optimal values. You initialize $\mathbf{w}$ and $b$ to random numbers!

The Initial State

A random initialization produces a completely random straight line on your data plot. Some red dots (negative class) are on the green side, and some green dots (positive class) are on the red side. The training algorithm's job is to adjust the slope and position of this line iteratively until every point is on the correct side!

02. The Perceptron Trick: Intuitive Heuristic

Nitish presents an intuitive physical metaphor: "Treat each misclassified point as a magnet with an active electric charge."

Suppose we pick a random training point $P(x_1, x_2)$ from our dataset. There are two error cases:

Case 1: False Negative ($y = 1, \hat{y} = 0$)

The point belongs to the Positive Class ($+1$), but currently lies on the negative side of the line ($\mathbf{w}^T \mathbf{x} + b < 0$).

Action Needed: Pull the decision line TOWARDS the point so that the point ends up on the positive side!
Case 2: False Positive ($y = 0, \hat{y} = 1$)

The point belongs to the Negative Class ($0$), but currently lies on the positive side of the line ($\mathbf{w}^T \mathbf{x} + b > 0$).

Action Needed: Push the decision line AWAY FROM the point so that the point is excluded to the negative side!

03. Vector Arithmetic of Moving the Line

How do we mathematically pull or push a line toward or away from a point $P(x_1, x_2)$?

Pulling the Line Toward a Positive Point:

To rotate the normal vector $\mathbf{w}$ towards the vector $\mathbf{x}$, we add the point's coordinates to our weights!

$$\mathbf{w}_{new} = \mathbf{w}_{old} + \eta \mathbf{x}$$ $$b_{new} = b_{old} + \eta$$

Pushing the Line Away from a Negative Point:

To rotate the normal vector $\mathbf{w}$ away from the vector $\mathbf{x}$, we subtract the point's coordinates from our weights!

$$\mathbf{w}_{new} = \mathbf{w}_{old} - \eta \mathbf{x}$$ $$b_{new} = b_{old} - \eta$$

05. The Unified Rosenblatt Perceptron Learning Rule

Instead of writing complex conditional if-else branches for Case 1 and Case 2, Frank Rosenblatt unified both cases into a single mathematical equation using the error term $(y_i - \hat{y}_i)$:

$$\mathbf{w}_{new} = \mathbf{w}_{old} + \eta \, (y_i - \hat{y}_i) \, \mathbf{x}_i$$
$$b_{new} = b_{old} + \eta \, (y_i - \hat{y}_i)$$

Let's verify why this formula is mathematically bulletproof using the three possible scenarios:

Scenario Actual $y_i$ Predicted $\hat{y}_i$ Error $(y_i - \hat{y}_i)$ Resulting Update
Correct Prediction 1 or 0 1 or 0 $1 - 1 = 0$ or $0 - 0 = 0$ $\mathbf{w} + 0 = \mathbf{w}$ (Zero change! Leave line alone.)
False Negative 1 0 $1 - 0 = \mathbf{+1}$ $\mathbf{w}_{new} = \mathbf{w}_{old} + \eta \mathbf{x}_i$ (Add → Pull line toward point!)
False Positive 0 1 $0 - 1 = \mathbf{-1}$ $\mathbf{w}_{new} = \mathbf{w}_{old} - \eta \mathbf{x}_i$ (Subtract → Push line away from point!)

06. Why the Learning Rate ($\eta$) is Essential

Nitish emphasizes why you cannot simply set $\eta = 1$:

The Danger of a Large Learning Rate

If a point is at coordinates $(100, 200)$ and $\eta = 1$, adding the full vector $[100, 200]^T$ to your weights will swing the decision line wildly across the entire coordinate plane! It will fix point $P$, but in doing so, it will misclassify 50 other points that were previously correct.

The Learning Rate $\eta$ (typically a small value like $0.1, 0.01$, or $0.001$) scales down the step size. It ensures the line takes small, cautious, incremental steps toward the misclassified point without violently disrupting the progress made on other training points.

07. Complete NumPy Implementation from Scratch

Here is the complete, self-contained Python implementation coded by Professor Nitish during the lecture:

# ======================================================== # PERCEPTRON FROM SCRATCH IN PURE NUMPY (CampusX Lecture 5) # ======================================================== import numpy as np from sklearn.datasets import make_classification class PerceptronFromScratch: def __init__(self, learning_rate=0.1, epochs=1000): self.lr = learning_rate self.epochs = epochs self.weights = None self.bias = None def _step_function(self, z): # Heaviside step: 1 if z >= 0, else 0 return np.where(z >= 0, 1, 0) def fit(self, X, y): n_samples, n_features = X.shape # 1. Initialize weights and bias to random or zero self.weights = np.ones(n_features) self.bias = 0.0 # 2. Iterate through epochs for epoch in range(self.epochs): # Pick a random sample index (Perceptron Trick uses stochastic picking) idx = np.random.randint(0, n_samples) x_i = X[idx] y_i = y[idx] # 3. Compute linear combination and prediction z = np.dot(x_i, self.weights) + self.bias y_hat = self._step_function(z) # 4. Apply unified Rosenblatt update rule error = y_i - y_hat self.weights += self.lr * error * x_i self.bias += self.lr * error def predict(self, X): z = np.dot(X, self.weights) + self.bias return self._step_function(z) # ======================================================== # TEST ON LINEARLY SEPARABLE DATA # ======================================================== X, y = make_classification(n_samples=100, n_features=2, n_redundant=0, n_informative=1, n_clusters_per_class=1, random_state=41) model = PerceptronFromScratch(learning_rate=0.01, epochs=1000) model.fit(X, y) predictions = model.predict(X) accuracy = np.mean(predictions == y) print(f"Perceptron Scratch Accuracy: {accuracy * 100:.2f}%")

08. Novikoff's Perceptron Convergence Theorem

Nitish concludes with a profound mathematical theorem proven by Albert Novikoff in 1962:

Novikoff's Convergence Guarantee

If the training dataset is strictly linearly separable (there exists at least one hyperplane that separates Class 0 from Class 1 with margin $\gamma > 0$), then the Perceptron learning algorithm is mathematically guaranteed to converge and find a separating boundary in a finite number of steps: $$k \le \left(\frac{R}{\gamma}\right)^2$$ where $R = \max \|\mathbf{x}_i\|$ is the maximum radius of the data points, and $\gamma$ is the geometric margin.

Crucial caveat: If the data is not linearly separable (like XOR or overlapping distributions), the perceptron algorithm will loop infinitely, cycling between errors forever! In Video 06, we will see how smooth Loss Functions and Sigmoid activations resolve this.

Module 01 Foundational Masterclass

Foundations of Deep Learning: Perceptron Topology, Activation Dynamics, Forward & Backward Propagation

A rigorous textbook guide to deep learning fundamentals: the mathematical anatomy of artificial neurons, linear algebra formulations, non-linear activation functions, empirical loss evaluation, multivariable calculus of backpropagation, and gradient descent optimization.

1. The Artificial Intelligence Taxonomy: AI vs ML vs DL vs Data Science

To understand modern deep learning, one must first delineate the technical taxonomy governing the intelligent systems landscape. In engineering practice, the terms Artificial Intelligence, Machine Learning, Deep Learning, and Data Science are frequently conflated. However, they represent distinctly nested sets and cross-cutting applied disciplines.

Figure 1.1: Euler diagram of the AI ecosystem depicting nested relationships (DL ⊂ ML ⊂ AI) alongside transversal Data Science integration.

1.1 Formal Taxonomy Definitions

  • Artificial Intelligence (AI) — The Universal Superset: The overarching engineering domain dedicated to constructing computing systems capable of performing cognitive tasks that conventionally necessitate human intelligence. An AI application operates with programmatic autonomy—perceiving external environmental state, inferring context, and executing goal-directed decisions without explicit step-by-step human intervention. Prominent exemplars include autonomous vehicular control (e.g., Tesla Autopilot), content recommendation graphs (Netflix, Amazon, YouTube), and conversational agent interfaces.
  • Machine Learning (ML) — Statistical Subset of AI: A specialized mathematical branch of AI wherein systems extract predictive patterns directly from historical empirical data ($\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$) rather than executing hard-coded rule-based heuristics. Machine learning is formalized through statistical modeling techniques spanning supervised learning (regression, classification), unsupervised learning (clustering, dimensionality reduction), and reinforcement learning.
  • Deep Learning (DL) — Architectural Subset of ML: A subdiscipline of machine learning centered on deep artificial neural networks (ANNs) characterized by hierarchical layered topologies. While traditional ML requires laborious manual feature engineering, deep learning networks extract representations automatically from raw high-dimensional perceptual data (pixels, audio waveforms, tokens) by cascading non-linear mathematical transformations across multiple hidden layers.
  • Data Science (DS) — Intersectional Domain: An applied multidisciplinary profession unifying statistical analysis, computer science, data engineering pipelines, distributed Big Data infrastructure, and machine learning to extract actionable intelligence and construct production-grade AI solutions from enterprise data.
💡
Key Distinction: All Deep Learning models are Machine Learning models, and all Machine Learning models are AI applications ($DL \subset ML \subset AI$). However, an AI application does not necessarily require Deep Learning—simple rule-based expert systems or decision trees can power autonomous logic.

2. The Deep Learning Paradigm Shift: Why Did DL Explode?

Artificial neural networks are not a recent conceptual invention. Frank Rosenblatt published the first computational perceptron model in 1958 at Cornell Aeronautical Laboratory. Why, then, did deep learning only achieve ubiquitous commercial and scientific dominance over the past decade? The exponential resurgence was catalyzed by the convergence of three foundational pillars:

2.1 The Three Convergence Catalysts

  1. Exponential Generation of Big Data (Web 2.0 & Telemetry): Prior to 2005 (Web 1.0 era), web interactions were predominantly static and consumed unidirectionally. The emergence of social interaction platforms (Facebook, WhatsApp, YouTube, Instagram, LinkedIn) and industrial IoT smart appliances (such as Panasonic connected air conditioning systems transmitting ambient telemetry) resulted in petabytes of continuous distributed data generation. Traditional statistical models (Linear Regression, Support Vector Machines) suffer from an algorithmic capacity limit: after a modest data threshold, their performance plateaus. Deep neural networks, endowed with high parameter capacity, scale monotonically as training data volume increases.
  2. Massive Hardware Parallelism (NVIDIA GPUs & Tensor Hardware): Deep learning requires billions of matrix multiplications ($\mathbf{W} \mathbf{x} + \mathbf{b}$). Traditional Central Processing Units (CPUs) possess a small number of complex execution cores optimized for low-latency sequential instructions. Graphics Processing Units (GPUs), pioneered by NVIDIA (e.g., RTX Titan, RTX 3090, A100), house thousands of concurrent lightweight streaming multiprocessors. By parallelizing linear algebra tensor operations across thousands of CUDA cores, model training epochs that previously required months were reduced to hours.
  3. Industrial Economics & Smart Product Monetization: Enterprises discovered that applying deep learning directly to proprietary operational data unlocked massive operational efficiencies. For example, in smart HVAC systems, training neural networks on indoor temperature curves and outdoor meteorological forecasts generates optimal thermal duty cycles, dramatically reducing peak energy consumption while creating new SaaS subscription revenue models.

3. Biological Foundations: Mimicking the Human Cortical Network

Deep learning takes direct architectural inspiration from the anatomical connectivity of biological nervous systems. The human brain contains roughly 86 billion neurons, interconnected through approximately $10^{14}$ adaptive synaptic junctions.

🧠 Biological Neuron
  • 1. Dendrites: Tree-like branch fibers that receive chemical neurotransmitter signals from sensory receptor organs or upstream neurons.
  • 2. Soma (Cell Body): Accumulates incoming electrical membrane potential by summing ionic concentration differentials.
  • 3. Axon: A long single transmission cable that conducts an action potential electrical spike if the accumulated threshold is reached.
  • 4. Synaptic Terminals: Microscopic gaps regulating signal transmission efficiency through chemical neurotransmitter concentration.
⚡ Artificial Perceptron
  • 1. Input Vector ($\mathbf{x}$): Numerical sensory features ($x_1, x_2, \dots, x_n$) received by the model.
  • 2. Linear Summation ($\mathbf{w}^T\mathbf{x} + b$): Accumulates weighted input signals into a net scalar continuous pre-activation potential ($z$).
  • 3. Non-Linear Activation ($\sigma(z)$): Firing threshold gate mapping continuous potential to an activated output state ($[0, 1]$).
  • 4. Synaptic Weights ($\mathbf{w}$): Adaptive scalar parameters calibrated via gradient descent to regulate connection strength.
Figure 1.3: Direct one-to-one architectural isomorphism between anatomical neurobiology and the computational perceptron.

3.2 The Biological Learning Analogy

Consider an infant observing the physical world. At birth, a human infant cannot autonomously categorize a video camera, a bottle of milk, or a spoken word. The infant's neural pathways lack calibrated synaptic connections for those specific stimuli.

Over months of repetitive sensory exposure, parental reinforcement signals, and iterative perceptual adjustments, specific neural circuits undergo synaptic plasticity (strengthening or weakening synaptic connections). Eventually, the infant identifies visual objects instantly. An artificial neural network functions identically: it initializes with uninformed or random weights, performs forward passes, compares predictions against ground-truth labels, and iteratively adjusts internal synaptic weights until empirical error approaches zero.

4. The Perceptron: Mathematical Topology & Input Vectors

The fundamental building block of every deep learning architecture is the Perceptron (Artificial Neuron). To formalize its mechanics, consider a binary classification problem: predicting whether a university student will Pass ($y = 1$) or Fail ($y = 0$) based on three independent observational features:

Record ($i$) Feature 1 ($x_1$): Study Hours Feature 2 ($x_2$): Play Hours Feature 3 ($x_3$): Sleep Hours Ground-Truth ($y$)
1 7.0 3.0 7.0 1 (Pass)
2 2.0 5.0 8.0 0 (Fail)
3 4.0 3.0 7.0 1 (Pass)
Figure 1.4: Detailed anatomical flow inside a Perceptron: Weighted combination with bias ($z$) followed by non-linear gating ($\sigma(z)$) to produce output hypothesis $\hat{y}$.

4.1 Mathematical Formulation of the Linear Combination

Given an input vector $\mathbf{x} \in \mathbb{R}^n$ and corresponding synaptic weight vector $\mathbf{w} \in \mathbb{R}^n$, the artificial neuron first computes the scalar inner product plus an additive scalar bias $b \in \mathbb{R}$:

$$z = \sum_{i=1}^n w_i x_i + b = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$$

This formulation is mathematically equivalent to multivariable linear regression ($y = \mathbf{\beta}^T \mathbf{x} + \beta_0$). Here, $z$ represents the net pre-activation continuous potential accumulated by the neuron.

5. Synaptic Weights & The Critical Architectural Role of Bias

5.1 The Biological Meaning of Weights

Weights ($w_i$) quantify the sensitivity, transmission efficiency, and relative importance of an input feature.

Consider a neurobiological stimulus: touching a boiling hot surface activates sensory nociceptors on the hand. High-strength synaptic weights immediately trigger the withdrawal reflex in the right hand without moving the left hand. In an artificial network, if Feature 1 (Study Hours) is strongly correlated with student success, training will drive $w_1$ to a large positive value ($w_1 \gg 0$). Conversely, if Feature 2 (Play Hours) is negatively correlated with passing, training will penalize $w_2$, forcing it toward a negative value ($w_2 < 0$).

5.2 The Mathematical Necessity of the Bias Term ($b$)

What occurs if an artificial neuron lacks a bias term ($z = \mathbf{w}^T \mathbf{x}$)?

  • The Origin Constraint Trap: If all input signals are zero ($\mathbf{x} = \mathbf{0}$), the pre-activation potential is permanently trapped at $z = \mathbf{w}^T \mathbf{0} = 0$. Consequently, the output is restricted to $\sigma(0) = 0.5$. Without a bias, the model cannot adjust its baseline threshold away from zero, regardless of what the optimal decision boundary requires.
  • Zero-Weight Initialization Deadlock: If weights are initialized to zeros ($\mathbf{w} = \mathbf{0}$), then $\mathbf{w}^T \mathbf{x} = 0$ for all records. The additive bias $b$ provides a learnable constant offset ensuring the network retains an adjustable activation baseline even during early training phases.
  • Geometric Translation: In analytical geometry, $b$ is the $y$-intercept ($c$ in $y = mx + c$). It translates the decision boundary hyper-plane along the feature axis without altering its orientation slope.
⚠️
Architecture Rule: Every dense neuron layer must incorporate its own independent bias parameter. A layer with $M$ inputs and $N$ neurons has $M \times N$ weight parameters and $N$ bias parameters, totaling $(M + 1) \times N$ learnable parameters.

6. Non-Linear Activation Functions & The Sigmoid Curve

If a neural network only executed linear combinations ($z = \mathbf{w}^T \mathbf{x} + b$), cascading one hundred consecutive layers would mathematically collapse into a single trivial linear transformation:

$$z^{(2)} = \mathbf{W}^{(2)}(\mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}) + \mathbf{b}^{(2)} = (\mathbf{W}^{(2)}\mathbf{W}^{(1)})\mathbf{x} + (\mathbf{W}^{(2)}\mathbf{b}^{(1)} + \mathbf{b}^{(2)}) = \mathbf{W}_{\text{effective}}\mathbf{x} + \mathbf{b}_{\text{effective}}$$

Such a network could never learn non-linear relationships. To shatter linearity, we introduce an activation function $\sigma(z)$ that transforms pre-activation potential $z$ into a non-linear activation state.

6.1 The Sigmoid (Logistic) Mathematical Formulation

For binary classification, the canonical activation function is the Sigmoid function, defined as:

$$\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

Mathematical Properties:

  1. Domain & Range: $\text{Domain: } z \in (-\infty, +\infty) \implies \text{Range: } \sigma(z) \in (0, 1)$.
  2. Asymptotic Limits: $\lim_{z \to +\infty} \sigma(z) = 1.0$, and $\lim_{z \to -\infty} \sigma(z) = 0.0$.
  3. Center-Symmetry: $\sigma(0) = \frac{1}{1 + e^0} = \frac{1}{2} = 0.5$, and $\sigma(-z) = 1 - \sigma(z)$.
  4. Analytic Derivative: The first derivative of the sigmoid function expresses elegantly in terms of its own output: $$\frac{d\sigma(z)}{dz} = \sigma(z)\bigl(1 - \sigma(z)\bigr)$$

6.2 Binary Decision Thresholding Rule

Because $\sigma(z) \in (0, 1)$, its continuous scalar output is interpreted as a posterior probability: $\hat{y} = P(y = 1 \mid \mathbf{x})$. To convert this probability into a discrete binary class prediction, a decision threshold $\tau = 0.5$ is applied:

$$\text{Prediction } \hat{y} = \begin{cases} 1 & \text{if } \sigma(z) \ge 0.5 \quad (\iff z \ge 0) \\ 0 & \text{if } \sigma(z) < 0.5 \quad (\iff z < 0) \end{cases}$$

7. Forward Propagation: Step-by-Step Computational Walkthrough

Forward Propagation is the process whereby sensory inputs traverse unidirectionally from the input layer, undergo linear weighting and non-linear gating at each neuron, and emit a final scalar or vector prediction $\hat{y}$.

7.1 Numeric Walkthrough with Lecture Data

Consider Record 1 from our student dataset: $$\mathbf{x} = \begin{bmatrix} 7.0 \\ 3.0 \\ 7.0 \end{bmatrix}, \quad \text{Ground-Truth } y = 1$$

Assume early training initialized synaptic weights and bias to initial scalar estimates: $$\mathbf{w} = \begin{bmatrix} 0.1 \\ -0.2 \\ 0.05 \end{bmatrix}, \quad b = -0.5$$

Step 1: Compute Linear Dot Product ($z$):

$$z = (w_1 x_1 + w_2 x_2 + w_3 x_3) + b$$ $$z = (0.1 \times 7.0) + (-0.2 \times 3.0) + (0.05 \times 7.0) + (-0.5)$$ $$z = 0.70 - 0.60 + 0.35 - 0.50 = -0.05$$

Step 2: Pass through Sigmoid Activation ($\hat{y}$):

$$\hat{y} = \sigma(-0.05) = \frac{1}{1 + e^{-(-0.05)}} = \frac{1}{1 + e^{0.05}} \approx \frac{1}{1 + 1.05127} \approx 0.4875$$

Step 3: Apply Binary Threshold ($\tau = 0.5$):

$$\because \hat{y} = 0.4875 < 0.5 \implies \text{Predicted Class } \hat{y}_{\text{discrete}} = 0 \text{ (Fail)}$$
🚨
Model Error Identified: The ground-truth label was $y = 1$ (Student Passed), yet our model predicted $\hat{y}_{\text{discrete}} = 0$ (Fail). The model made an incorrect prediction because its synaptic weights are suboptimal. We must now quantify this error and correct the weights.

8. Loss Functions: Quantifying Error & The Objective Function

To systematically train a neural network, we must mathematically measure how far its predicted hypothesis $\hat{y}$ deviates from the true target $y$. This quantification is performed by a Loss Function $\mathcal{L}(y, \hat{y})$.

8.1 Intuitive Residual vs. Binary Cross-Entropy Loss

  • Simple Difference (Residual): $$e = y - \hat{y} = 1 - 0 = 1 \quad (\text{or } 1.0 - 0.4875 = 0.5125)$$ While intuitive, a raw difference can be positive or negative, creating cancellation artifacts across training batches.
  • Binary Cross-Entropy Loss (Log-Loss): The standard objective function for binary classification derived from maximum likelihood estimation:
    $$\mathcal{L}(y, \hat{y}) = -\Bigl[ y \ln(\hat{y}) + (1 - y) \ln(1 - \hat{y}) \Bigr]$$
    When $y = 1$, the right-hand term vanishes, leaving $\mathcal{L} = -\ln(\hat{y})$. If $\hat{y} \to 1$, loss $\to 0$. If $\hat{y} \to 0$, loss $\to +\infty$, penalizing incorrect, confident predictions heavily.
  • Mean Squared Error (MSE Loss) for Regression: $$\mathcal{L}_{\text{MSE}}(y, \hat{y}) = \frac{1}{2}(y - \hat{y})^2$$
🎯
The Fundamental Optimization Objective: The ultimate mathematical goal of deep learning is to find a set of optimal parameters $\mathbf{w}^*$ and $b^*$ that minimize the aggregate loss over all training instances: $$\mathbf{w}^*, b^* = \arg\min_{\mathbf{w}, b} \frac{1}{N} \sum_{i=1}^N \mathcal{L}(y^{(i)}, \hat{y}^{(i)})$$

9. Backward Propagation: The Multivariable Calculus of Gradients

Once the loss $\mathcal{L}$ is computed, how do we adjust each weight? We cannot blindly guess billions of parameter values. Instead, we use Backward Propagation, which applies the Chain Rule of Differential Calculus to calculate the exact partial derivative of the loss function with respect to every weight $w_i$ and bias $b$.

Figure 1.6: The closed-loop deep learning optimization cycle: Forward evaluation → Loss formulation → Reverse chain-rule differentiation → Parameter optimization.

9.1 Analytical Derivation via Chain Rule

The partial derivative $\frac{\partial \mathcal{L}}{\partial w_i}$ indicates how much the total loss $\mathcal{L}$ changes given an incremental change in weight $w_i$. Decomposing through the intermediate variables $\hat{y}$ and $z$:

$$\frac{\partial \mathcal{L}}{\partial w_i} = \underbrace{\frac{\partial \mathcal{L}}{\partial \hat{y}}}_{\text{Loss Gradient}} \times \underbrace{\frac{\partial \hat{y}}{\partial z}}_{\text{Activation Derivative}} \times \underbrace{\frac{\partial z}{\partial w_i}}_{\text{Linear Input}}$$

Solving each factor analytically for binary cross-entropy with a sigmoid activation:

  1. $\frac{\partial \mathcal{L}}{\partial \hat{y}} = -\frac{y}{\hat{y}} + \frac{1 - y}{1 - \hat{y}} = \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})}$
  2. $\frac{\partial \hat{y}}{\partial z} = \sigma'(z) = \hat{y}(1 - \hat{y})$
  3. $\frac{\partial z}{\partial w_i} = \frac{\partial}{\partial w_i}(w_1 x_1 + \dots + w_i x_i + b) = x_i$

Multiplying these terms together reveals an elegant algebraic cancellation:

$$\frac{\partial \mathcal{L}}{\partial w_i} = \left[\frac{\hat{y} - y}{\cancel{\hat{y}(1 - \hat{y})}}\right] \times \cancel{\hat{y}(1 - \hat{y})} \times x_i = (\hat{y} - y) \, x_i$$

Similarly, for the scalar bias term $b$ (since $\frac{\partial z}{\partial b} = 1$):

$$\frac{\partial \mathcal{L}}{\partial b} = (\hat{y} - y)$$

10.1 The Parameter Update Rules

The gradient vector $\nabla_{\mathbf{w}} \mathcal{L}$ always points in the direction of the steepest ascent (greatest increase in loss). Consequently, to minimize loss, we step in the exact opposite direction of the gradient:

$$w_i^{(\text{new})} = w_i^{(\text{old})} - \alpha \frac{\partial \mathcal{L}}{\partial w_i} = w_i^{(\text{old})} - \alpha (\hat{y} - y) x_i$$ $$b^{(\text{new})} = b^{(\text{old})} - \alpha \frac{\partial \mathcal{L}}{\partial b} = b^{(\text{old})} - \alpha (\hat{y} - y)$$

where $\alpha > 0$ represents the Learning Rate (step size).

  • If $\alpha$ is excessively large: The optimizer overshoots the minimum and may diverge into numerical overflow.
  • If $\alpha$ is excessively small: Training becomes prohibitively slow and can stall in flat plateaus.

11. Multi-Layer Perceptrons (MLP) & Deep Topologies

A single perceptron can only delineate linearly separable datasets (such as logical AND/OR gates). To learn complex, non-linear geometric decision manifolds (such as logical XOR gates, computer vision features, and speech patterns), we assemble multiple neurons into layered cascades termed Multi-Layer Perceptrons (MLP).

Figure 1.8: Architectural topology of a 4-layer Deep Neural Network (MLP): 3 Input features → 4 Hidden units (Layer 1) → 3 Hidden units (Layer 2) → 2 Output logits.

11.1 Matrix Formulation of Deep Layers

In a deep neural network, computations are vectorized across entire layers. For any layer $l \in \{1, 2, \dots, L\}$:

$$\mathbf{z}^{[l]} = \mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}$$ $$\mathbf{a}^{[l]} = \sigma^{[l]}\bigl(\mathbf{z}^{[l]}\bigr)$$

where $\mathbf{a}^{[0]} = \mathbf{x}$ is the raw input vector, $\mathbf{W}^{[l]}$ is the parameter weight matrix of shape $(n^{[l]}, n^{[l-1]})$, and $\mathbf{b}^{[l]}$ is the bias vector of shape $(n^{[l]}, 1)$.

Task 1: Vectorized Perceptron Forward Pass NumPy Implementation

Objective: Implement a single-neuron forward pass from scratch in Python using pure NumPy for the lecture student exam dataset. Compute the linear combinations, apply the sigmoid activation function, and output both continuous probabilities and discrete pass/fail classifications.

python 
# perceptron_forward.py
import numpy as np

def sigmoid(z):
    """Numerically stable Sigmoid activation function."""
    return 1.0 / (1.0 + np.exp(-z))

def perceptron_forward(X, weights, bias):
    """
    Executes a vectorized forward pass across all input samples.
    """
    # Step 1: Linear combination z = X . w + b
    z = np.dot(X, weights) + bias
    
    # Step 2: Non-linear activation gate
    probabilities = sigmoid(z)
    
    # Step 3: Decision boundary threshold at 0.5
    predictions = (probabilities >= 0.5).astype(int)
    
    return z, probabilities, predictions

# Student Dataset: [Study Hours, Play Hours, Sleep Hours]
X_train = np.array([
    [7.0, 3.0, 7.0],  # Record 1: Ground Truth = Pass (1)
    [2.0, 5.0, 8.0],  # Record 2: Ground Truth = Fail (0)
    [4.0, 3.0, 7.0]   # Record 3: Ground Truth = Pass (1)
])

# Calibrated synaptic weights reflecting feature contributions
weights = np.array([0.85, -0.65, 0.15])
bias = -1.5

z_scores, probs, preds = perceptron_forward(X_train, weights, bias)

print("--- PERCEPTRON FORWARD PASS OUTPUTS ---")
for i in range(len(X_train)):
    status = "PASS" if preds[i] == 1 else "FAIL"
    print(f"Student {i+1}: z = {z_scores[i]:.2f} | Probability = {probs[i]:.4f} | Prediction = {status}")

Task 2: Empirical Loss Computation Engine Loss Functions

Objective: Implement both Mean Squared Error (MSE) and Binary Cross-Entropy (BCE / Log-Loss) with numerical clipping to prevent $\log(0)$ runtime errors. Compute the exact penalty associated with true vs predicted probabilities.

python 
# loss_engine.py
import numpy as np

def compute_losses(y_true, y_pred_prob):
    """
    Computes both MSE and Binary Cross-Entropy loss.
    """
    # Prevent numerical instability: clip probabilities to [1e-15, 1 - 1e-15]
    eps = 1e-15
    y_clipped = np.clip(y_pred_prob, eps, 1.0 - eps)
    
    # 1. Mean Squared Error (MSE)
    mse = np.mean(0.5 * (y_true - y_pred_prob) ** 2)
    
    # 2. Binary Cross-Entropy (BCE)
    bce = -np.mean(y_true * np.log(y_clipped) + (1.0 - y_true) * np.log(1.0 - y_clipped))
    
    return mse, bce

# Ground truth vs Model Predictions
y_true = np.array([1.0, 0.0, 1.0])
y_predicted_prob = np.array([0.9721, 0.0601, 0.7311])

mse_loss, bce_loss = compute_losses(y_true, y_predicted_prob)

print(f"Evaluated Batch MSE Loss: {mse_loss:.5f}")
print(f"Evaluated Batch BCE Loss: {bce_loss:.5f}")

Task 3: Full End-to-End Perceptron Training Loop Gradient Descent Optimization

Objective: Construct an end-to-end training loop for a single perceptron. Initialize weights and bias to zeros, execute forward propagation, compute analytical gradients via backpropagation, and apply gradient descent updates across 100 epochs.

python 
# perceptron_trainer.py
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

# Normalized Features: Study, Play, Sleep
X = np.array([
    [0.7, 0.3, 0.7],  # Pass (1)
    [0.2, 0.5, 0.8],  # Fail (0)
    [0.4, 0.3, 0.7],  # Pass (1)
    [0.1, 0.8, 0.9]   # Fail (0)
])
y = np.array([1, 0, 1, 0])

n_samples, n_features = X.shape
weights = np.zeros(n_features)
bias = 0.0
learning_rate = 0.5
epochs = 100

print("--- STARTING GRADIENT DESCENT TRAINING LOOP ---")
for epoch in range(1, epochs + 1):
    # 1. Forward Pass
    z = np.dot(X, weights) + bias
    y_hat = sigmoid(z)
    
    # 2. Binary Cross-Entropy Loss
    loss = -np.mean(y * np.log(y_hat + 1e-15) + (1 - y) * np.log(1 - y_hat + 1e-15))
    
    # 3. Backward Pass (Analytical Gradients)
    error = y_hat - y
    grad_w = np.dot(X.T, error) / n_samples
    grad_b = np.sum(error) / n_samples
    
    # 4. Parameter Updates (Optimizer Step)
    weights -= learning_rate * grad_w
    bias -= learning_rate * grad_b
    
    if epoch in [1, 10, 50, 100]:
        print(f"Epoch {epoch:3d} | Loss: {loss:.4f} | Weights: {weights.round(3)} | Bias: {bias:.3f}")

print("\n--- FINAL TRAINED MODEL INFERENCE ---")
final_preds = (sigmoid(np.dot(X, weights) + bias) >= 0.5).astype(int)
print(f"Ground Truth : {y}")
print(f"Predictions  : {final_preds}")
print(f"Final Accuracy: {np.mean(final_preds == y) * 100:.1f}%")

# mlp_forward.py
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

# Architecture Dimensions
n_input = 3
n_hidden1 = 4
n_hidden2 = 3
n_output = 1

np.random.seed(42)

# Parameter Initialization
W1 = np.random.randn(n_input, n_hidden1) * 0.1
b1 = np.zeros((1, n_hidden1))

W2 = np.random.randn(n_hidden1, n_hidden2) * 0.1
b2 = np.zeros((1, n_hidden2))

W3 = np.random.randn(n_hidden2, n_output) * 0.1
b3 = np.zeros((1, n_output))

# Input Batch (2 samples)
X = np.array([
    [7.0, 3.0, 7.0],
    [2.0, 5.0, 8.0]
])

# Layer 1
Z1 = np.dot(X, W1) + b1
A1 = sigmoid(Z1)

# Layer 2
Z2 = np.dot(A1, W2) + b2
A2 = sigmoid(Z2)

# Output Layer
Z3 = np.dot(A2, W3) + b3
A3 = sigmoid(Z3)

print("--- MULTI-LAYER PERCEPTRON FORWARD PROPAGATION ---")
print("Input Batch Shape       :", X.shape)
print("Hidden Layer 1 Output A1:", A1.shape)
print("Hidden Layer 2 Output A2:", A2.shape)
print("Final Output Predictions:\n", A3)

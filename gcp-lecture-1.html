Cloud Architecture, Billing & Console Navigation

What is this lecture about? This module establishes the ground-floor foundations of Google Cloud Platform (GCP). We demystify what the cloud actually is using the simple Uber rental mental model, break down the three core service tiers (IaaS, PaaS, SaaS), clarify why Google Workspace is completely different from Google Cloud, guide you step-by-step through setting up your $300 free trial account safely, tour the real Google Cloud Console UI, configure proactive budget alerts to eliminate bill shock, and install, authenticate, and configure the Google Cloud CLI (gcloud).
Why is this critical for engineers? In modern software engineering and Agentic AI, your local computer does not have the high-memory GPU clusters, terabyte vector stores, or auto-scaling infrastructure required to run production workloads. Cloud lets you rent enterprise-grade supercomputing infrastructure on demand, paying only for the exact seconds your application executes.

01. The Mental Model: What is Cloud Computing?

1. The "Uber Car Rental" Analogy

Think about how you travel to a hill station or office. If you own a private car, you must pay upfront for the vehicle purchase, ongoing maintenance, insurance, tire changes, fuel, and parking space. But what if you don't own a car or don't want the liability?

You simply open your phone and book an Uber. You rent the car for the exact distance of your trip, reach your destination, pay only for what you consumed, and walk away. You don't care about oil changes or garage repairs.

The Core Definition of Cloud:

Cloud computing is simply renting someone else's high-power computers, massive storage, and software over the internet on a pay-as-you-go model.

2. Why Cloud is Non-Negotiable for AI Engineers & Developers

  • High-End GPUs on Demand: Running modern Large Language Models (LLMs) or fine-tuning diffusion models requires enterprise GPUs (NVIDIA H100, A100, L4) that cost tens of thousands of dollars to buy physically. On GCP, you can spin one up for an hour, run your experiment, and shut it off.
  • Infinite Elastic Storage: AI agents and enterprise systems generate gigabytes to petabytes of unstructured documents, embeddings, and transaction tables daily. Cloud storage scales automatically without buying physical hard drives.
  • Instant Scalability: If your web app has 10 users at 3 AM and spikes to 1,000,000 users at noon, the cloud automatically spins up new server instances to handle the traffic, and shrinks back down when traffic subsides.
  • Pay-Only-For-What-You-Use: If a virtual machine runs for 17 minutes, you are billed for exactly 17 minutes—not a penny more.

02. The 3 Cloud Service Models (IaaS, PaaS, SaaS)

Everything Google Cloud provides over the internet falls into one of three architectural tiers. Think of it like building a modern city:

Service Model City Analogy What Google Provides What You Manage GCP Examples
IaaS
Infrastructure as a Service		 Raw roads, bridges, and power lines Physical data centers, server hardware, networking cables, hypervisors Operating System (Linux/Windows), runtime, code, data, security patches Compute Engine (VMs), Persistent Disk, Virtual Private Cloud (VPC)
PaaS
Platform as a Service		 City bus or subway system (pre-built transit) Hardware, OS, networking, auto-scaling, load balancers, container runtime Just your application code and configuration! (Zero server management) Cloud Run, App Engine, Cloud Functions
SaaS
Software as a Service		 A fully furnished, staffed hotel room Complete, working software product ready to use immediately Your data, user settings, and application integrations Gmail, Google Docs, Google Sheets, Google Maps Platform
💡 Developer Tip: As an AI engineer, Cloud Run (PaaS) is your secret weapon. You write your FastAPI or LangChain code in VS Code, push your container image, and Cloud Run instantly gives you an HTTPS URL that scales from 0 to 1,000 instances automatically.

03. The Critical Distinction: Google Cloud vs. Google Workspace

One of the most widespread pitfalls among beginners is confusing Google Cloud with Google Workspace. Let's make this crystal clear:

🏢 Google Workspace (For End Users)

A suite of pre-built productivity SaaS applications designed for ordinary office workers and students:

  • Gmail, Google Docs, Google Sheets, Google Drive, Google Calendar
  • You don't configure servers or manage virtual machines here
  • You use the software as-is to write documents or send emails

☁️ Google Cloud Platform (For Developers & Engineers)

A massive developer cloud infrastructure ecosystem used to build, deploy, scale, and monitor your own custom software:

  • Compute Engine, Cloud Storage, Vertex AI, BigQuery, Cloud Run
  • Targeted at developers, data scientists, and cloud architects
  • Fun Fact: Google uses GCP internally to power Google Drive, YouTube, and Gmail!

04. $300 Free Trial Setup & Financial Safety

1. What the Free Trial Gives You

  • $300 USD (Approx. ₹28,000+ INR) Free Credits: Valid for a full 90 days.
  • Access to All Flagship GCP Services: You can spin up Compute Engine VMs, create Cloud Storage buckets, query BigQuery, and test Vertex AI models without paying out of pocket.
  • Always Free Tier: Even after the trial ends, GCP provides specific monthly allowances that remain 100% free indefinitely (e.g., 1 e2-micro VM in US regions, 5 GB Cloud Storage, 1 TB BigQuery queries/month).

2. The Verification Step (Why You Are Charged ₹1,000 / $1)

During sign-up, Google will ask for your credit card or UPI/QR code and initiate a temporary verification transaction (usually ₹1,000 INR or $1 USD):

✅ Don't Panic: This is not a payment for usage. It is an automated banking verification check to confirm that you are a genuine human user rather than an automated bot abusing free trial servers. In most cases, this authorization amount is refunded back to your account.

3. The Golden Rule of Free Trial Safety

⚠️ Will Google Auto-Bill My Bank Account When 90 Days End?
NO. Google Cloud explicitly guarantees that your bank account will NEVER be automatically billed once your 90-day trial expires or your $300 credit is exhausted. Your services will simply pause. Google will only charge your payment method if you manually click the button to upgrade to a full paid account.

06. Billing Accounts & Budget Alerts (Preventing Bill Shock)

1. The Infamous Cloud Billing Meme

If you browse programmer communities on Reddit or Twitter, you've probably seen the classic meme: "How did you end up in poverty? Gambling? Drugs? — No, I left an EC2 / GPU VM instance running overnight."

Why does this happen? Because on the cloud, nothing turns off by itself. If you spin up an expensive GPU machine to test a model and go on vacation without shutting it down, it will happily keep running 24/7 and generate a massive invoice.

2. What is a Billing Account?

  • A Billing Account is how Google Cloud collects money. It tracks all resource charges across projects.
  • Key Rule: Every GCP project must be linked to a Billing Account before you can enable APIs or deploy servers. If a project has no linked billing account, it remains completely dormant.

3. Setting Up a Budget Alert Step-by-Step

To protect yourself, set a strict monthly budget (e.g., $10 or ₹1,000) with threshold alert triggers:

Navigation Menu ☰ ➔ Billing ➔ Budgets & alerts ➔ Create Budget
  1. Scope: Select your target project (e.g., gcloud-basics) and choose "All Services".
  2. Amount: Set your target monthly budget (e.g., $10 USD or ₹1,000 INR).
  3. Actions / Thresholds: Configure email notifications when actual spend reaches 50% ($5), 90% ($9), and 100% ($10).
🚨 CRITICAL REALITY CHECK:
Budget alerts NOTIFY you via email; they DO NOT AUTOMATICALLY KILL OR SHUT DOWN your servers! Google will not pull the plug on your live production app during a traffic spike just because it crossed a budget threshold. When you receive an alert, you must log in and manually stop idle virtual machines yourself!

4. Creating a Budget via `gcloud` CLI

bash 
# 1. List your available billing accounts to grab your Billing Account ID
gcloud billing accounts list

# 2. Create a budget alert for $10 with threshold alerts at 50%, 90%, and 100%
gcloud billing budgets create \
  --billing-account="012345-6789AB-CDEF01" \
  --display-name="course-monthly-budget" \
  --budget-amount=10USD \
  --threshold-rule=percent=0.5 \
  --threshold-rule=percent=0.9 \
  --threshold-rule=percent=1.0

# 3. Verify that your budget alert is active
gcloud billing budgets list --billing-account="012345-6789AB-CDEF01"

07. Google Cloud CLI (`gcloud`) Setup & First Commands

While the web console is excellent for visual exploration, professional cloud engineers interact with GCP via the command line interface (CLI). The CLI allows rapid scripting, Infrastructure as Code, CI/CD pipeline automation, and managing 10+ projects in seconds.

1. Installation

  • Windows: Download and run the official GoogleCloudSDKInstaller.exe. It bundles Python and adds gcloud to your system PATH.
  • macOS (Homebrew): brew install --cask google-cloud-sdk
  • Linux (Debian/Ubuntu): sudo apt-get install google-cloud-cli

2. Verifying Installation

Open Command Prompt (Windows) or Terminal (Mac/Linux) and test:

bash 
gcloud version

You should see output similar to:

Terminal Output 
Google Cloud SDK 480.0.0
bq 2.1.8
core 2026.05.10
gsutil 5.30

3. Initial Authentication (`gcloud auth login`)

Connect your local terminal to your Google Cloud account:

bash 
# Initiates browser-based OAuth2 login
gcloud auth login
  1. Your default browser opens with Google's authentication page.
  2. Select the Google account you used to register the GCP Free Trial.
  3. Click Allow to grant Google Cloud SDK management permissions.
  4. Return to your terminal: You will see You are now logged in as [your-email@gmail.com].

4. Setting Account & Checking Active Config

bash 
# Set your active account explicitly
gcloud config set account your-email@gmail.com

# List all authenticated credentials stored on your machine
gcloud auth list

# Inspect your currently active configuration (account, project, zone)
gcloud config list

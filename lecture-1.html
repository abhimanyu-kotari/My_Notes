Variables and Data-Types

What is this topic? Variables are like labeled storage boxes in your computer's memory that hold information, while Data-Types tell Python what kind of value is inside (like text, whole numbers, or decimals).
Why do we use it? We use variables in every single program to store and track data—like a player's score in a game, a user's login name, or the price of an item in a shopping cart—so our program can remember and calculate with that data.

01. What is Programming & Why Python?

1. What is Programming?

At its core, programming is the process of giving instructions to a computer (or machine) so it can perform specific tasks or solve problems.

Just like you use human languages (such as English, Spanish, or Hindi) to communicate with people in different countries, you use a Programming Language to communicate with a computer.

Definition: Python

Python is a modern, high-level, general-purpose, and interpreted programming language created by Guido van Rossum and first released in 1991. It is designed to be easy to read and simple to write, resembling plain English.

Why is Python so Popular?

  • Simple and Beginner-Friendly: Python syntax looks almost like normal English sentences. You don't have to worry about complex syntax like semicolons or manual memory management.
  • Free and Open Source: Anyone can download Python completely free from python.org, inspect its source code, and use it for commercial or personal projects.
  • Platform-Independent (Portable): A Python program written on Windows runs on macOS and Linux without changing a single line of code.
  • Extremely Versatile: With Python, you can build:
    • Artificial Intelligence & Machine Learning (using libraries like TensorFlow, PyTorch, scikit-learn)
    • Data Science & Analysis (using Pandas, NumPy, Matplotlib)
    • Web Development Backends (using frameworks like Django, Flask, FastAPI)
    • Automation & Scripting (automating boring manual tasks, web scraping)
    • Games & Desktop Software (using Pygame, Tkinter)

02. How Computers Run Python Code

1. The Problem: Computers Don't Understand English or Python Directly

Inside every computer, your CPU (processor) is composed of billions of tiny electronic switches (transistors). These switches can only be in one of two states:

  • Current flowing (High voltage): Represented as 1
  • No current flowing (Low voltage): Represented as 0

This language of zeros and ones (0 and 1) is called Machine Language (Binary Code). Physical computer hardware can only understand and execute binary machine code. It does not understand English words like print, if, or while.

2. High-Level vs. Low-Level Languages

Category High-Level Languages (e.g. Python, Java, C++) Low-Level Languages (Machine Code, Assembly)
Readability Easy for humans to read, write, and understand (resembles English). Hard for humans to read; written in raw binary (01010101) or hardware mnemonics.
Portability Can run on any operating system (Windows, Mac, Linux). Tied strictly to one specific processor architecture (x86, ARM).
Execution Cannot run directly on CPU; must be translated first. Executed directly by the computer processor.

3. The Role of a Translator: Compilers vs. Interpreters

Since we write code in a human-friendly High-Level Language (Python), but the computer only understands Machine Language (0s and 1s), we need a Translator in between.

Compiler (e.g., C, C++)

Translates the entire program all at once into a standalone machine executable file (like a .exe) before running it. If there is even one error anywhere, it will not run at all.

Interpreter (e.g., Python)

Translates and executes the program line by line. It reads Line 1, translates it, executes it, then moves to Line 2. If it encounters an error on Line 5, Lines 1 to 4 will still run successfully before the program stops.

💡
The Complete Execution Pipeline

When you write Python code and click Run in VS Code:

  1. You write readable Python code in a file ending with .py (e.g., first_program.py).
  2. The Python Interpreter reads your file line by line.
  3. It converts the Python instructions into an intermediate form called Bytecode and then directly executes it on your computer CPU.
  4. The result appears on your terminal screen as the Output!

03. Your First Code & The print() Function

Definition: The print() Function

In Python, print() is a built-in function used to display output (messages, numbers, calculations, or variables) on the computer screen or console.

1. Writing Your First Program

By tradition in programming, the very first program you write in any language is "Hello World". Create a file named first_program.py and write:

python 
print("Hello World")
Terminal Output:
Hello World

2. When to Use Quotes vs. When NOT to Use Quotes

Item to Print Do you use Quotes? Example Code Output
Plain Text / Words / Sentences YES (Must be inside quotes) print("My name is John") My name is John
Numbers (Integers, Decimals) NO (Write directly) print(23) 23
Math Calculations NO (Evaluates the math) print(35 + 23) 58
Variables NO (Prints value inside variable) print(age) 23
⚠️
The Quotes Trap: Value vs. Text

Compare these two lines:
• print("23 + 35") → Outputs exact text: 23 + 35
• print(23 + 35) → Computes and outputs: 58
Anything inside quotes is treated strictly as literal text (a string). Outside quotes, Python evaluates it as numbers and code!

3. Printing Multiple Items on the Same Line

You can print multiple items together in a single print() call by separating them with a comma (,). Python will automatically insert a space between each item:

python 
print("My name is John.", "My age is", 23)
Terminal Output:
My name is John. My age is 23

4. How print() Handles New Lines

By default, every separate print() statement automatically moves the cursor to the next line:

python 
print("Line 1")
print("Line 2")
Terminal Output:
Line 1
Line 2

If you want to prevent a newline, you can customize the end parameter:

python 
print("Hello", end=" ")
print("World!")
Terminal Output:
Hello World!

04. Python Character Set

A character set is the complete set of valid characters that Python can recognize in code:

  • Letters: Both uppercase A – Z and lowercase a – z.
  • Digits: Numbers from 0 – 9.
  • Special Symbols: Standard keyboard symbols like +, -, *, /, %, =, _, ( ), [ ], { }, :, " ", ' ', #.
  • Whitespaces: Blank space, Tab (\t), Newline (\n).
  • Unicode: Python 3 supports full UTF-8 encoding (supporting characters and symbols from world languages inside text strings).

05. Variables & How Memory Works

Definition: Variable

A variable is a named container in computer memory used to store data values. Whenever you need to save a number, a piece of text, or a calculation result to use later in your program, you store it inside a variable.

1. The Storage Box Analogy

Imagine your computer's RAM memory as a large warehouse full of empty storage boxes.

When you write:
age = 23

Python does two things behind the scenes:

  1. It reserves a spot in memory and puts the value 23 inside it.
  2. It sticks a label named age on that memory spot.

Whenever you write print(age) later in your program, Python looks up the box labeled age, reads its value (23), and displays it.

2. The Assignment Operator (=)

In Python, the single equal sign = is called the Assignment Operator.

⚠️
Important: In Python, = does NOT mean "Equal To"

In school mathematics, x = y means $x$ is equal to $y$.
In Python programming, = means:
"Take whatever value is on the RIGHT side, and store it into the variable on the LEFT side."
Data always flows from Right → Left.

3. Dynamic Typing (No Need to Declare Types)

In older languages like C, C++, or Java, you are forced to tell the computer what type of data you want to store in advance (e.g., int age = 23;).

In Python, you never have to declare data types manually. Python is dynamically typed: it looks at whatever value you put on the right side and automatically figures out the data type!

python 
# Creating variables of different types
name = "Shraddha"    # Python automatically knows this is text (string)
age = 23             # Python automatically knows this is an integer
price = 25.99        # Python automatically knows this is a decimal number (float)

print("My Name is:", name)
print("My Age is:", age)
print("Product Price is:", price)
Terminal Output:
My Name is: Shraddha
My Age is: 23
Product Price is: 25.99

4. Variable Reassignment (Values Can Change)

The word variable comes from the word vary (meaning to change). You can change the value stored in a variable at any point:

python 
age = 23
print(age)  # Prints 23

# Next year, update the age
age = 24
print(age)  # Now prints 24! The old value 23 is replaced.

5. Assigning One Variable to Another

You can copy the value of one variable into a second variable:

python 
age = 25
age2 = age  # Takes value of 'age' (25) and puts it into 'age2'

print(age2)  # Prints 25

06. Rules for Naming Variables (Identifiers)

Definition: Identifier

An identifier is simply the name you give to something in your Python code — such as a variable name, a function name, or a class name.

The 5 Strict Rules You Must Follow (Syntax Errors if Broken)

  1. Permitted Characters: An identifier can only consist of:
    • Letters: a – z and A – Z
    • Digits: 0 – 9
    • Underscore: _
  2. Cannot Start with a Digit: A variable name can have numbers in the middle or end, but never at the very beginning.
    • var1 → Valid
    • 1var → SyntaxError
  3. No Special Symbols or Spaces: Symbols like @, $, %, #, !, - or blank spaces are strictly forbidden in variable names.
    • my_age → Valid
    • my age → Invalid (Space not allowed)
    • user-id → Invalid (Hyphen is treated as minus sign)
  4. Cannot Use Python Keywords: You cannot name a variable after reserved language words like class, def, for, True, or None.
  5. Python is Case-Sensitive: Uppercase and lowercase letters are treated as completely different things!
    • age, Age, and AGE are three completely separate variables in memory.
Variable Name Valid? Explanation
user_score Valid Contains lowercase letters and underscore. Excellent name.
score_1 Valid Digits are allowed after the first character.
_internal_val Valid Starting with an underscore is fully permitted.
2nd_user INVALID Cannot begin with the number 2.
total$price INVALID The $ symbol is illegal in identifiers.
user name INVALID Spaces are not allowed. Use user_name instead.
True INVALID True is a reserved Python keyword.
✨
Professional Tip: Best Naming Practices (PEP 8)

Always choose names that are short, simple, and meaningful:
• Bad name: x or xybde (Nobody knows what data is inside it).
• Bad name: this_is_the_total_sum_of_all_items_in_the_cart (Too long and tedious to type).
• Good names: age, name, total_price, count, sum_result.

07. The 5 Fundamental Data Types & type()

Definition: Data Type

A data type tells Python what kind of value a variable is holding. Knowing the data type is critical because it determines what operations you are allowed to perform.
(For example, you can multiply two numbers together, but you cannot multiply a person's name by a shoe size!)

The 5 Core Primary Types in Python:

1. Integer (int)

Represents whole numbers without any decimal point. They can be positive, negative, or zero:

Examples: 25, -25, 0, 1000

2. Floating-Point Number (float)

Represents decimal numbers (fractions). Any number containing a decimal point is treated as a float:

Examples: 25.99, 3.14, -0.5, 2.0 (even 2.0 is a float because of the decimal point!)

3. String (str)

Represents text — characters, words, or sentences enclosed in quotes. You can write strings in three ways:

  • Double quotes: name = "Shraddha" (Standard convention)
  • Single quotes: name = 'Shraddha' (Useful if your text contains double quotes)
  • Triple quotes: name = '''Shraddha''' or """Shraddha""" (Useful for multi-line paragraphs)

4. Boolean (bool)

Represents a logical truth condition. A boolean can only ever have one of two values:

True or False

⚠️ Crucial Rule: The first letter MUST be capitalized: True and False. Writing true or false with lowercase letters will give a NameError!

5. None (NoneType)

Used to represent the absence of any value (similar to null in other programming languages). If you create a variable but don't want to store any data in it yet, you assign it None:

Example: a = None (Capital N is required).

Checking a Variable's Data Type with type()

Python has a built-in function called type() that inspects any variable and tells you its exact data type:

python 
name = "Shraddha"
age = 23
price = 25.99
is_adult = True
a = None

print(type(name))
print(type(age))
print(type(price))
print(type(is_adult))
print(type(a))
Terminal Output:
<class 'str'> ← string
<class 'int'> ← integer
<class 'float'> ← floating-point number
<class 'bool'> ← boolean
<class 'NoneType'>← none type

08. Python Keywords & Case Sensitivity

Definition: Keywords

Keywords are special words that are reserved by Python for its own internal syntax and rules. Each keyword has a specific, fixed meaning.

Because these words are reserved, you cannot use them as variable names. For instance, you cannot name your variable True, class, or break.

Common Python Keywords:

False None True and as assert break class continue def del elif else except finally for from if import in is lambda not or pass return try while
💡
Do you need to memorize all keywords now?

No! You will learn them naturally one by one as we progress through loops, conditionals, and functions. Just remember that reserved words cannot be used as variable names.

Understanding Case Sensitivity

In SQL, SELECT and select are the same. But Python is strictly case-sensitive:

  • apple, Apple, and APPLE are 3 completely separate variables.
  • Keywords like True, False, and None must begin with a capital letter. If you write true, Python thinks you are searching for a variable named true and gives a NameError!

09. Comments in Python

Definition: Comments

A comment is a note written by the programmer inside the code to explain what the code does. Comments are completely ignored by the Python interpreter and will never execute.

Why Write Comments?

  • To make your code easy to understand for team members or your future self.
  • To temporarily disable ("comment out") lines of code during debugging without deleting them.

Types of Comments:

python 
# 1. Single-Line Comment: Starts with a '#' symbol
age = 23  # This is an inline comment explaining this variable

# 2. Multi-Line Comment using multiple '#' symbols (Recommended PEP 8 way)
# This program calculates the
# final price of groceries
# after applying holiday discounts.

# 3. Multi-Line Comments using Triple Quotes (""" or ''')
"""
You can also write multi-line explanations
inside triple quotation marks. If not assigned
to a variable, Python discards it.
"""

print("Hello World")  # Only this line will actually execute!

VS Code Shortcut

Select any line or block of code and press:
• Windows / Linux: Ctrl + /
• macOS: Cmd + /
This instantly comments or uncomments the selected lines.

10. Operators in Python

Definition: Operators & Operands

An operator is a symbol that performs a specific operation on values or variables.
The values on which the operation is performed are called operands.
In the expression 5 + 2, the numbers 5 and 2 are operands, and + is the operator.

10.1 Arithmetic Operators (Mathematical Calculations)

Used to carry out basic math:

Operator Name Description Example ($a=5, b=2$) Result
+ Addition Adds two values together. a + b 7
- Subtraction Subtracts right value from left value. a - b 3
* Multiplication Multiplies two numbers. a * b 10
/ Division Divides numerator by denominator. Always gives a float! a / b 2.5
// Floor Division Divides and drops the decimal part (rounds down to whole number). a // b 2
% Modulus (Remainder) Returns the remainder after division. a % b 1 (because $5 \div 2 = 2$ with remainder $1$)
** Power / Exponent Calculates $a$ raised to the power of $b$ ($a^b$). a ** b 25 (because $5^2 = 25$)
💡
Golden Rule: Division in Python Always Produces a Float

In Python, the division operator / always returns a decimal number (float), even if the division is perfectly even!
• print(4 / 2) → outputs 2.0 (not 2).
If you want an integer answer without decimals, use floor division: 4 // 2 → outputs 2.

10.2 Relational / Comparison Operators

Used to compare two values. Relational operators always return a boolean: either True or False.

Operator Meaning Example ($a=50, b=20$) Result
== Equal to (checks if both values are equal) a == b → Is 50 equal to 20? False
!= Not equal to (checks if values are different) a != b → Is 50 not equal to 20? True
> Greater than a > b → Is 50 greater than 20? True
< Less than a < b → Is 50 less than 20? False
>= Greater than or equal to a >= b → Is 50 greater than or equal to 20? True
<= Less than or equal to a <= b → Is 50 less than or equal to 20? False

10.3 Assignment Operators (Compound / In-Place)

We already learned the basic assignment operator (=). Python also gives you convenient shorthand assignment operators to modify a variable's value in-place:

Shorthand Full Equivalent Example ($num = 10$) New Value of $num$
num += 10 num = num + 10 Adds 10 to current value 20
num -= 5 num = num - 5 Subtracts 5 from current value 5
num *= 2 num = num * 2 Multiplies current value by 2 20
num /= 2 num = num / 2 Divides current value by 2 5.0
num %= 3 num = num % 3 Stores remainder after dividing by 3 1
num **= 2 num = num ** 2 Raises current value to power of 2 100

10.4 Logical Operators (not, and, or)

Logical operators work on boolean values (True and False) to build decision logic:

1. not (Opposite)

Flips the boolean value to its exact opposite:
• not True → False
• not False → True

2. and (Both must be True)

Returns True only if BOTH conditions are True. If even one condition is False, the result is False:
• True and True → True
• True and False → False

3. or (At least one True)

Returns True if either of the conditions is True. It only returns False if both are False:
• True or False → True
• False or False → False

python 
a = 50
b = 30

print(not (a > b))           # not (50 > 30) -> not (True) -> False
print((a > 20) and (b > 20))  # (True) and (True) -> True
print((a == b) or (a > b))   # (False) or (True) -> True
Terminal Output:
False
True
True

11. Type Conversion vs. Type Casting

Often in programming, you need to change a variable from one data type to another (for example, turning the string "25" into the actual integer number 25).

The Fundamental Difference
  • Type Conversion (Automatic / Implicit): Python converts the type automatically behind the scenes to protect you from losing data.
  • Type Casting (Manual / Explicit): You, the programmer, manually tell Python to convert a type using built-in functions like int(), float(), or str().

1. Type Conversion (Automatic)

When you add an integer and a float together, Python automatically promotes the integer to a float:

python 
a = 2       # int
b = 4.25    # float

sum_val = a + b  # Python automatically treats 'a' as 2.0
print(sum_val)        # 6.25
print(type(sum_val))  # <class 'float'>

2. Type Casting (Manual)

If you have a number trapped inside quotes as a string (like "25"), Python will NOT automatically convert it for you. If you try to add "2" + 4.25, Python will throw a TypeError.

You must manually convert it using type casting functions:

python 
# Converting String to Integer: int()
a = "2"
a_converted = int(a)    # Now 'a_converted' is the integer number 2
print(a_converted + 5)  # Prints 7

# Converting String to Float: float()
price_str = "25.99"
price_num = float(price_str)
print(price_num + 1.0)  # Prints 26.99

# Converting Number to String: str()
age = 23
age_str = str(age)      # Becomes the string "23"
print(type(age_str))   # <class 'str'>
🚨
Watch Out: Converting Invalid Text Causes ValueError

Type casting only works if the string actually looks like a number!
• int("25") → Works cleanly! (Becomes 25)
• int("shraddha") → Crashes with ValueError! Python cannot turn English letters into a number.

12. Taking User Input in Python: input()

Definition: The input() Function

The input() statement pauses program execution and waits for the user to type something on their keyboard and press the Enter key. Whatever the user types is saved into a variable.

1. Basic Syntax

python 
name = input("Enter your name: ")
print("Welcome", name)
Terminal Execution:
Enter your name: Shraddha
Welcome Shraddha

2. THE GOLDEN RULE of input(): It ALWAYS Returns a String!

No matter what the user types into the terminal — whether it is their name, an integer like 25, or a decimal like 99.99 — Python will ALWAYS read it as a String (str)!

⚠️
The Classic Beginner Bug: "10" + "20" = "1020"

Look at what happens if you don't convert input when taking numbers: 

a = input("Enter first number: ")   # User types 10 -> a is "10"
b = input("Enter second number: ")  # User types 20 -> b is "20"
print(a + b)                         # Prints "1020", NOT 30!

Because a and b are strings, the + operator concatenates (glues) them together rather than adding them mathematically!

3. How to Properly Take Number Inputs (Wrapping with int() or float())

To take numbers from a user, wrap the input() call directly inside int() or float():

python 
# Taking an Integer Input
age = int(input("Enter your age: "))

# Taking a Floating-Point (Decimal) Input
price = float(input("Enter item price: "))

# Taking a String Input (No casting needed)
name = input("Enter your name: ")

print("User:", name)
print("Age in 5 years:", age + 5)  # Real math works!
print("Price with tax:", price + 2.50)
